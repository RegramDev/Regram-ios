## 过滤消息与 @ 提示

过滤仅从聊天显示列表移除消息，原先依赖显示节点触发的提及已读动作因此缺失。现在从未过滤的原始历史中选取当前会话／话题、普通云端、收到的、读过位置以内且确实被隐藏的未消费提及，逐条交给原有提及同步队列。

读历史开关、前台可读状态、支持账号限制与普通已读位置继续生效；同一可见位置发生过滤变化也会处理。可见提及、读过位置以后的消息、其他话题不由这条自动处理路径清除。

主动点击 @ 时，查找会逐条跳过被隐藏的提及；被跳过的 ID 立即从后续查询中排除，避免慢网或离线等待服务端确认时反复命中同一条。加载、补历史洞和频道状态检查继续沿用原有查询。忽略列表耗尽不触发全会话的提及清除或历史摘要修复。

## 设置分类内整理

首页保留全局搜索和九类入口；每类增加简短内容说明，分类和复杂编辑器复用 Telegram 设置图标，说明支持换行。沿用 Telegram 主题、glass 导航、控件和返回手势。

| 分类 | 调整 |
| --- | --- |
| 聊天与消息 | 消息操作／聊天列表／分组改为同页标签；消息总结接口和菜单编辑器仍可单独打开 |
| 输入与发送 | 输入工具、发送行为和盘古开关在同一分类分组展示 |
| 翻译与语音 | 翻译服务直接选择；LLM 与语音识别直接打开各自编辑器 |
| 隐私与过滤 | 过滤和保护入口、隐私显示开关、动态开关集中展示 |
| 媒体与链接 | 播放与链接／照片／贴纸／录制改为同页标签 |
| 外观与界面 | 个性化、界面显示、账号颜色与资料显示在同一分类；底栏直接进入布局编辑器 |
| 通知与提醒 | 保留直接设置的通知策略与过滤开关 |
| 网络与传输 | 连接／诊断入口、上传下载选项与通话选项集中展示 |
| 管理与工具 | 保留本地 Premium、备份、更新与数据清理，补充分组和图标 |

底栏路径由「Regram Pro → 外观与界面 → 界面与底栏 → 底栏布局」变为「Regram Pro → 外观与界面 → 底栏布局」。首页不增设底栏等快捷项。

既有偏好读写和备份字段没有迁移；分类复用原控件及其实际写入逻辑。每行绑定所属设置页的参数、设置标签和深链，不因嵌入其他分类而变成错误地址。旧设置页链接通过同一解析器进入新分类，并为聊天和媒体选择对应标签。搜索结果辅助说明更新为当前分类名称。三种语言资源同步更新。

样图是使用生产中文文案和示例值生成的独立原生 UIKit 布局预览，展示分类组织方式；不是完整应用截图，也不构成应用验收。
