## 消息工具与网络策略

书签管理入口位于设置首页「我的收藏」下方，使用原生列表；Regram Pro 中不保留重复入口。旧书签深链继续可用。普通会话和话题跳转分开处理，话题描述由 Telegram 引擎获取。

消息总结接口位于 Regram Pro 的聊天与消息分类，使用独立的地址、协议、模型、温度、提示词和钥匙串密钥。默认关闭，关闭时不显示消息菜单和工具栏入口。支持获取当前会话或话题的最近一小时、今天、最近一天或自定时间范围后再确认上传，也可总结单条及多选消息；无自动媒体附件。时间范围最多 5000 条、64 KB，超限要求缩小范围，不截断提交；多选最多 100 条，秘密聊天、一次性媒体和受保护消息不参与。可取消请求和复制结果，结果不会自动发回聊天。

消息截图仅导出单条，保留头像、文字和媒体，不带气泡背景；已有名字不重复，连续消息省略名字时补上，遵从当前剧透显示状态。贴纸包菜单可导出 ZIP 备份，保留原始文件与 pack.json 中的顺序、表情及包名；不包含账号或访问凭据。备份用于本机保管，不保证重新创建已删除的服务端贴纸包。


DNS 与 IP 策略位于网络与传输分类。DoH 按 [RFC 8484](https://www.rfc-editor.org/rfc/rfc8484) 使用 application/dns-message，以 HTTPS POST 查询 A／AAAA，校验响应、问题、记录所属域名和长度，按 TTL 有界缓存，可取消请求。默认关闭；启用后失败不自动退回系统 DNS。它用于原生 Telegram 传输的代理域名；DC 已有数字地址，HTTP 服务、网页和 Web 代理仍由系统解析。DoH 服务器域名的初始解析也由系统完成。IP 策略提供自动／优先 IPv4／优先 IPv6，保留可达回退。

验证：DNS 报文与恶意／截断响应回归检查、设置及备份隔离检查、本地化检查；编译结果与真机验证范围以本轮交付说明为准。

代理页的「使用系统 DNS」与自定义 DoH 互斥，恢复冲突配置时以 DoH 为准，保存后重建原生传输。DNS 与 IP 策略提供独立测试页，分别查询 A／AAAA，显示地址与解析耗时，不读取应用内 DNS 缓存、不把另一地址族的回退当作成功；可取消，退出页面停止测试。复制 DC 平均 Ping 和消息总结后立即显示已复制，过滤性能测试可取消。

底栏沿用上游 Telegram 的玻璃组件、动画与手势，保留排序、标签显隐、独立按钮和手动百分比设置。自动宽度兼顾文字、选中动效与点击间距，标签较多时充分使用可用空间，保持整体居中。
