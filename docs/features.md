# Regram 功能清单

本文按 **13.1.1 / b34638** 的源码整理当前功能、入口与限制。阅读概要可用[中文 README](../README.md)／[English README](../README.en.md)；逐版修正见[近期更新记录](changelog.md)。本轮更新见[消息搜索、归档与每日任务](search-archive-daily-34636.md)。

## 设置与导航

功能配置集中在 **设置 → Regram Pro**，首页提供全局搜索与十个分类。分类内直接展示基础设置；聊天与消息、媒体与链接通过文件夹式原生横栏切换相关选项，不增加返回层数。复杂编辑器保留独立页面，每个配置项保留一条可见路径。

| 分类 | 分类内容 |
| --- | --- |
| 聊天与消息 | 消息总结接口、消息动作与显示、聊天列表、分组 |
| 输入与发送 | 输入工具栏、默认格式、盘古空格、会话独立输入设置、输入与发送选项 |
| 翻译与语音 | 翻译、LLM 翻译、语音转文字 |
| 隐私与过滤 | 消息过滤、隐藏用户、防删除与限制解除、防撤回会话、撤回记录、幽灵模式、动态及隐私选项 |
| 媒体与链接 | 链接预览修复、照片与画质、贴纸、录制与播放 |
| 外观与界面 | 字体、应用图标、截图 App Badge、底栏布局、资料显示 |
| 通知与提醒 | 实验性通知恢复、置顶、提及／回复策略、消息通知过滤 |
| 网络与传输 | DNS 与 IP 策略、传输设置、性能与传输／DC1–DC5 连接测试 |
| 显摆一下 | 本地 Premium、星币／TON 礼物与升级模拟、装扮、手机号、评级和 TON 资料卡 |
| 管理与工具 | 设置备份、清除全部数据 |

搜索覆盖整个 Pro 的设置项和高级配置，结果显示所属页面，点击后打开并定位；分类页不重复放置设置搜索框或常用区。简体中文、繁体中文和英文文案随应用语言切换，页面共用导航、返回与主题配色。设置及 Regram 新增功能页统一采用 Telegram 分组列表、语义颜色与 glass 导航；旧系统沿用上游回退。布局约定和验证边界见[界面记录](settings-appearance.md)。

设置首页右下角原生搜索与 Pro 首页共用设置目录、页面定位、别名及 Unicode 匹配。无结果会移除旧结果，清空恢复默认内容；连续输入和输入法组合文字受到保护。复查路径、检查与交付边界见[本轮记录](groups-settings-search-drag-fixes.md)。

长按设置项可复制深链，例如：

```text
tg://rg/settings?page=bottomBar
tg://rg/settings?page=summary&item=enabled
tg://rg/settings?page=networkPolicy&item=ipVersion
```

链接与搜索使用同一目的地索引，只导航和定位，不更改配置或执行清除／安装，不携带账号、保存值或凭据。移动过的设置保留目的地迁移。调试路由为 `tg://rg/debug` 和 `tg://rg/rgdebug`。

**消息书签与标签**单独位于设置首页「我的收藏」下方。单个聊天的备注、过滤与防撤回等操作从相应资料页进入。

实现入口：[Pro 分类](../Regram/RGProUI/Sources/RGProUI.swift)、[搜索索引](../Regram/RGStrings/Sources/RGSettingsCatalog.swift)、[深链](../Regram/RGStrings/Sources/RGSettingsLink.swift)。

## 共同群组发言

从对方个人资料页的「更多 → 共同群组发言」进入独立列表，合并当前账号可访问的共同群组搜索结果，按时间倒序显示；支持按群筛选、暂停／继续、失败重试和加载更多。点结果返回原消息及其所属话题，已升级群组的旧群历史沿用原消息位置。

只查询服务端允许当前账号搜索的内容，不恢复删除或不可见消息；匿名管理员及以频道身份发送的内容不归入该用户。结果遵守本机消息过滤和剧透设置。离开页面或进入后台时取消请求，继续需回到页面；后台暂停后由用户手动继续，不在后台持续扫描。

b34624 的共同群组页面使用人物摘要、胶囊群组筛选、圆形查询操作按钮、群头像及分开的时间和正文；空结果、暂停、失败和加载状态采用一致样式。已随完整 App 编译通过，用户已确认最终包本机测试通过，尚无本页逐项设备验收记录。

## 消息操作、显示与编辑历史

- 单击消息菜单默认关闭，覆盖普通气泡、贴纸及圆视频；开启后仍保留独立双击动作。取消消息置顶可增加确认。
- 双击可选关闭、发送回应、显示回应、回复、复读、无引用复读、翻译及编辑；无法编辑的消息可以单独设置或跟随统一动作。
- 消息菜单可启停和排序常用已实现操作，以及当前账号实际生成过的特殊操作。消息类型和权限仍决定操作是否出现，菜单设置不授予管理权限。
- 复读保留转发来源；无引用复读保留完整富文本结构、内嵌媒体与原分组，以自己的消息重新发送，加载失败明确提示；无引用转发选择目标并隐藏发送者归属。
- 群组／频道可显示消息 ID；消息时间可显示秒数，转发来源可显示原消息时间。
- 自动显示剧透默认关闭，覆盖文字、图片、视频及图库说明；开启前保留剧透遮罩。
- 可控制回应显示、频道底部面板、消息宽度、删除特效及进入下一未读频道／话题的导航行为。

编辑历史开关位于 **隐私与过滤 → 防删除与限制解除 → 保存消息编辑历史**，长按有记录的消息查看。

| 记录内容 | 限制 |
| --- | --- |
| 文字、说明、实体、结构化富文本、图片替换及图片剧透变化 | 只保存本机观察到的旧版本，不恢复此前未收到的修改 |
| 版本数量 | 每条消息最多 50 个历史条目，保留原始版本 |
| 图片持久化 | 已取得的图片数据随消息记录保存，不依赖可清理的普通媒体缓存；单版最多 8 MiB，每条消息最多 32 MiB 图片数据 |
| 超出图片预算 | 丢弃部分旧预览字节，保留版本元数据；版本数量限制仍适用 |
| 历史图片查看 | 预览、放大及缩放；未保存字节时可主动尝试获取旧资源，引用失效则不能保证取回 |
| 排除范围 | 不持久保存秘密聊天、阅后即焚及受保护图片的历史数据 |

实现参考：[消息菜单](../submodules/TelegramUI/Sources/ChatInterfaceStateContextMenus.swift)、[历史记录](../submodules/TelegramCore/Sources/Utils/RGEditHistory.swift)、[历史存储格式](../submodules/TelegramCore/Sources/SyncCore/SyncCore_RGEditHistoryMessageAttribute.swift)。

## 消息过滤、防撤回与隐私

| 功能 | 当前行为 |
| --- | --- |
| 关键词／正则 | 匹配普通文字及标题、表格、列表、引用和媒体说明；ICU 正则、隐藏／保留动作、全局或限定会话 |
| 规则管理 | 添加、编辑、启停、JSON 导入合并去重及导出；从消息／选中文字快捷添加 |
| 规则测试 | 查看命中、禁用、非法表达式与超时结果，异常正则采用协作式进度超时 |
| 隐藏发送者 | 在本机隐藏指定用户／机器人的消息，可集中管理及解除 |
| 会话例外 | 关闭当前会话的关键词／正则规则；不同时解除发送者隐藏 |
| 临时恢复 | 临时查看该会话隐藏内容，最长五分钟恢复；不改变通知过滤 |
| 列表联动 | 隐藏内容不继续充当聊天预览；规则或消息变化刷新判定缓存 |
| 防撤回 | 全局或逐会话保留已收到、随后被撤回或批量清理的内容与媒体；用户主动删除仍执行 |
| 撤回记录 | 按聊天分页查看、搜索已加载的普通／富文本记录、定位及清理本机保留内容；暂时无法获取与明确撤回分开标记 |
| 删除与保存控制 | 已接入路径中的普通聊天／秘密聊天本地计时、截图通知、受保护消息及动态保存控制 |
| 隐藏赞助消息 | 聊天赞助消息及全局搜索赞助结果 |
| 列表预览与活动 | 可隐藏收藏夹／归档预览及收到的私聊输入、上传等活动，不改变自己的上报策略 |
| 动态入口 | 顶部动态条、列表头像打开动态和侧滑拍摄分别控制，沿用全局隐藏动态开关 |
| 幽灵模式 | 不上报动态浏览、在线状态及输入活动；不包含普通聊天已读回执屏蔽 |

**已撤回消息标记**位于防删除与限制解除内，可选择图标、自定义文字或不显示。文字留空使用当前语言默认值，颜色留空跟随时间文字，支持六位十六进制色值。颜色只影响标记，不改变正文及时间；保存／恢复配置后刷新已显示消息，并纳入隐私类别备份。

防撤回只覆盖已经到达本机的内容，媒体是否仍可打开取决于保留数据或可访问资源。幽灵模式不是不可见保证，发送消息等行为仍可能影响服务端在线判断。

实现参考：[过滤模型](../Regram/RGSimpleSettings/Sources/MessageFilter.swift)、[统一过滤](../submodules/AccountContext/Sources/RGContentFilter.swift)、[隐私控制](../Regram/RGProUI/Sources/RGPrivacyToolsController.swift)、[撤回标记](../Regram/RGSimpleSettings/Sources/RGRevokedMarker.swift)。

## 输入与发送

- 格式面板：引用、剧透、粗体、斜体、等宽、链接、下划线、删除线、代码块、清除格式和换行。
- 默认发送格式：关闭、加粗、斜体、下划线、删除线或剧透；保留手工格式，跳过代码、引用及自定义表情等片段。
- 盘古之白集中在「输入与发送」的同一设置组，分别控制接收、发送、编辑；发送开关沿用现有保存值及会话独立配置。
- 编辑入口及接收展示的盘古空格独立控制，默认关闭；接收转换保护代码、链接、提及及自定义表情范围。
- 选中文字菜单可挑选样式、排序与插入位置；格式工具栏保留现有开关、布局和行为。
- 自动 inline bot 查询默认关闭，只将单独输入的匹配 HTTP(S) 链接交给规则中的机器人，不提交旁边的草稿文字；规则页只读。
- 按账号／聊天覆盖默认格式与盘古空格，或继承全局设置。
- 长按头像插入完整昵称；可将输入的用户名解析为用户 ID 提及实体，解析依赖用户名及网络可用性。
- 回车发送实时作用于两种原生输入后端和旧输入框；关闭时换行，输入法确认、多行插入和硬件键盘独立处理。支持隐藏录音按钮、控制以其他身份发送按钮、表情键盘默认页及标准表情优先。
- 可关闭发送后的链接预览，输入阶段仍可查看草稿预览。

富文本基础能力包括所见即所得编辑器、标题、折叠引用、代码、列表、任务、表格、链接、图片／视频、拼贴／轮播及草稿；接入发送、编辑、复制、粘贴、Markdown 与 InstantPage 渲染。部分入口受上游配置控制，AI 服务、轮播视频等组合仍有边界，详见[富文本输入](richtext-composer.md)及[渲染说明](instantpage-richtext.md)。

## 翻译与网页翻译

入口：**翻译与语音 → 翻译**；LLM 配置从翻译子页进入。

| 能力 | 当前范围 |
| --- | --- |
| 翻译后端 | Telegram、Apple、Google、Google CN、Microsoft、Yandex、腾讯 TranSmart、LLM；重复旧服务值合并迁移 |
| LLM | OpenAI Chat Completions／Anthropic Messages 格式，自定义地址、模型列表、测试、提示词和温度 |
| 可选上下文 | 默认关闭；开启后最多附带同一会话／话题之前 5 条本机消息，每条最多 800 字 |
| 翻译入口 | 单条、聊天及置顶内容、发送前翻译；可记住账号／会话目标语言 |
| 格式保护 | 链接、代码、提及、嵌套实体、空白与 UTF-16 范围恢复，长文本分段及语言代码归一化 |
| 网页翻译 | 应用内浏览器菜单发起，沿用翻译服务及应用目标语言，分批处理可访问正文，可取消或恢复原文 |

Apple 翻译需要 iOS 18 或更新版本。网页表单、可编辑内容、代码、隐藏节点、图中文字及不可访问的 iframe 不提交；导航后丢弃旧任务，后续动态内容可恢复后重新翻译。富文本文章的 AI 翻译沿用上游路径，不等同于这里的 LLM 接口。

翻译 API Key 保存在本机钥匙串，不进入设置备份。服务连通、语言支持、额度与费用取决于提供方。

## 独立大模型消息总结

入口：**聊天与消息 → 消息总结接口**。

- 默认关闭；关闭时隐藏消息菜单及多选工具栏按钮。
- 使用独立于翻译的接口配置和凭据，支持 OpenAI／Anthropic 格式、模型列表、模型测试、提示词与温度。
- 可按当前聊天／话题的最近一小时、今天、最近一天或自定时间范围获取文字，也可使用单条／多选消息。
- 提交前展示文字与范围，用户确认后才调用接口；结果可复制并即时显示反馈。
- 时间范围最多 5000 条、64,000 字节文字；单条／多选最多 100 条。超限要求缩小范围，不静默截断提交。
- 读取完整富文本正文；范围加载任意一页失败即停止并提示，不提交部分结果。不上传附件，排除秘密聊天、一次性和受保护内容。凭据保存在本机钥匙串，不进入备份。

## 语音与圆视频识别

入口：**翻译与语音 → 语音转文字**。

- 统一选择 Telegram、Apple 或自定义 OpenAI-compatible Transcriptions API。
- 自定义 Base URL／Endpoint、模型、语言、提示词和密钥，支持内置测试音频。
- 获取完整媒体后提取音轨，转为单声道 M4A，上传并将结果写回原消息；文件上限 25 MB。
- 支持普通云消息的语音与圆视频，排除秘密聊天、一次性媒体及预览。
- 结果可复制、继续翻译、取消及重新识别。同一消息共享正在进行的任务，过期回调不覆盖新结果；后台或账号移除时取消任务。
- Telegram 后端仍遵守服务端权限和额度，切换后端不删除已有转写。

接口细节见[语音、链接与设置说明](speech-links-settings.md)。

## DNS、IP 策略、代理与诊断

入口：**网络与传输 → DNS 与 IP 策略**。

| 设置 | 当前行为 |
| --- | --- |
| 内置 DNS | Google／Cloudflare HTTPS 解析，备用服务有延迟竞争、合并请求、取消及短期缓存 |
| 系统 DNS | 代理域名使用 iOS 解析；与自定义 DoH 统一为互斥解析方式 |
| 自定义 DoH | 默认关闭；HTTPS 地址，DNS JSON，地址查询兼容 DNS 报文接口；失败不自动降级到系统解析 |
| 备用 DC | 自定义解析接入 TXT 查询，保留原有签名及有效期校验，可关闭额外备用地址发现 |
| 自动 | 使用可用地址及连接策略，域名代理优先复用短时成功地址 |
| 优先 IPv4／IPv6 | 首选地址族优先尝试，允许另一地址族回退 |
| 仅 IPv4／IPv6 | DNS 地址查询、DC 及代理候选、实际原生连接限制为指定地址族 |
| 应用设置 | 保存后重建原生连接；旧配置及备份按统一解析方式迁移，避免系统 DNS 与 DoH 同时启用 |

域名 SOCKS5／MTProto 代理保留多个 IPv4／IPv6 候选。连接失败或四秒没有响应时轮换，重建连接及握手，成功地址缓存五分钟；设置显式偏好时仅在同一地址族内提前成功地址。数字 IP 仍检查严格地址族限制。

**作用范围**为原生 Telegram DC、SOCKS5／MTProto 代理及接入的备用配置解析。网页、HTTP API、Web 代理及 DoH 自身连接走系统网络；解析服务域名仍需系统引导。设置不会改变整个设备的网络策略。

**DNS 测试**为独立页面，主动查询 A／AAAA，显示返回地址、策略允许的顺序及解析耗时，不读取应用内 DNS 缓存；可取消，退出页面停止。不将另一地址族回退当作当前类型成功，解析耗时也不是 Telegram 连接时延。

**性能与传输 → DC1–DC5 连接测试**是独立二级页面，使用当前账号 Telegram 网络及代理路径：

- 显示当前直连／代理方式、所属 DC 和连接状态。
- 首次请求包括连接／授权建立，随后三次 RPC 往返采样，显示平均、最低、波动、失败及超时。
- DC1／3 标为 Miami、DC2／4 Amsterdam、DC5 Singapore；标签只表示常用 DC 地区。
- 按钮启动、可取消，离页／后台／切换代理停止；复制只包含 DC1–DC5 平均 Ping，立即提示已复制。
- 保留本次运行媒体响应统计、最近三秒速率，以及每次 100 条合成消息的规则性能测试。

下载／上传加速调整分块和并发等传输参数，通话可 Force TCP；实际速度依赖网络与服务器。诊断流量不包含所有协议开销，规则耗时不等于手机帧率。

实现参考：[策略模型](../Regram/RGSimpleSettings/Sources/RGNetworkPolicy.swift)、[DC 测试](../Regram/RGProUI/Sources/RGDatacenterDiagnostics.swift)、[DNS 测试页](../Regram/RGSettingsUI/Sources/RGDNSDiagnosticsController.swift)。
