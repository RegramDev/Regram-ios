## 修正

1. 旧定位提示将额外 UIView 加到整行最上方，使用的 node bounds 包含分组布局间距，覆盖文字／开关，并绕过原生圆角遮罩。现在调用实际设置行的 `ItemListItemNode.displayHighlight()`：焦点背景使用原生内容坐标，绘制在内容和遮罩之后，自行淡出；保留延迟查找、单次提示和离开页面取消旧查找回调的逻辑。
2. 应用通过导航控制器的状态栏代理调用顶层 `ViewController.scrollToTop`，独立 UITableView 的默认回顶响应并不接入此路由。共同群组发言页和筛选页现在同时注册该回调，并关闭 table 自身的 scrollsToTop 以避免与代理竞争。回调使用 `-adjustedContentInset.top`，不依赖是否存在第一行，保留横向偏移，弱引用 table。
3. 筛选页原先继承上页「用户名 · 共同群组发言」作为返回文案，左侧宽度过大导致导航栏将标题偏向右侧。共同群组页面为下一页指定系统本地化的短「返回」文案，保留当前页的完整标题，并随展示语言变化更新。
