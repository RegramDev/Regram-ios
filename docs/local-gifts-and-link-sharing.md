# 本地星币、礼物与链接分享

当前行为按 Telegram 13.1.1 / Regram b34633 整理，见[本轮更新](profile-notifications-34633.md)。保留现有底栏、设置导航与 Telegram 主题，本地定制功能只在本机生效。文末保留 b34631 的历史交付记录。

## 入口与购买

设置 → Regram Pro → **显摆一下**。专区将本地会员、本地星币／TON 与礼物购买、手机号显示放在一起。首页入口沿用其他分类的彩色圆角方形图标、标题、灰色功能说明和右箭头，不增加插画或横幅。各开关独立，原会员设置值保留；本地礼物和手机号显示默认关闭。设置页编辑余额，使用 Telegram 星币／TON 图标，不提供独立礼物目录或购买按钮。旧会员、工具页礼物和 catalog／owned 设置链接会转到新专区对应项，设置搜索同步。

启用并保存余额后，从 Telegram 原有的送礼物／给自己购买礼物页面选择普通礼物，或在原生收藏礼物商店选购星币或 TON 报价的收藏礼物。目录、搜索、筛选、价格图标、预览及收藏礼物确认框沿用上游，列表不再受独立页面中“图片必须已缓存”的筛选限制。目录与预览仍按 Telegram 正常流程联网加载。

普通礼物在请求付款表单前结束本地购买；收藏礼物在原生确认后、余额检查、充值和购买 RPC 前结束本地购买，详情也不预取真实付款表单。星币与 TON 使用独立本地账本；TON 按整数 nanotons 扣款，编辑器支持最多 9 位小数，不进行兑换、链上转账或真实充值。已打开的本地确认框即使被关闭开关，也不能改走真实付款。本地拍卖入口仅模拟按所选报价取得本地礼物，不提交真实竞拍；Premium 赠送及其他真实钱包操作沿用原流程。

本地购买成功扣除本地余额，保存礼物图片快照和记录，并在自己的个人资料页展示。即使从其他人的送礼入口购买，也只添加到自己的本地记录，不发送礼物或聊天消息。未加载完的图片、余额不足或存储失败均不产生成功记录。星币范围 0–9000000000000000，TON 范围 0–9000000，最多 500 份本地礼物。旧账本的星币和礼物保留，补充默认本地 TON 余额。

## 本地限定礼物升级

普通礼物仍直接进入 Telegram 原生结算页，保持绕过转售的现有方式。在自己的资料礼物列表打开可升级的本地限定礼物，使用原生详情的升级入口。目录和升级预览正常读取，升级基于已缓存的模型、图案和背景生成本机收藏礼物，只扣当前报价对应的本地星币。原记录保留本地 ID、日期和显示状态，扣款与更新一次写入；余额不足、资源或存储失败不改变记录，重复的旧确认不能再次扣款。旧版已购的本地礼物也会读取可用升级预览。

## 个人资料与保存范围

本地记录和 Telegram 真实礼物只在显示时合并，不写入服务端上下文；账号没有真实礼物时也显示礼物标签。普通和收藏礼物使用 Telegram 原生礼物卡片，类型筛选与本地价格排序包含收藏礼物。收藏礼物模型、可用的图案和背景保存在本机，移除原持有人、真实 slug、钱包地址和出售等数据；不产生真实藏品所有权。

本地礼物点击与长按进入 Telegram 原生礼物弹层，右上角“更多”提供删除，底部显示／隐藏链接只修改本地记录；原来的独立本地详情页移除。隐藏、删除、购买及开关变化同时刷新礼物网格和标签旁的小预览，真实详情的左右切换排除本地记录。限定普通礼物支持本地升级；不能转赠、出售、兑换、加入服务端收藏夹或用于服务端操作。移除不退还本地星币。正式／测试环境和账号分别保存；关闭开关隐藏记录，重新开启恢复。本地账本与图片不进入设置导出；原测试包已购买的普通礼物继续读取。

Telegram 星星／TON 余额页、外层设置余额、礼物页面与购买确认框同步投影本地值；真实 StarsContext、TON 状态和交易记录不变。点击这些礼物页面的本地余额进入设置编辑，不打开充值或真实钱包。大额余额使用 Int64 格式化。

本地收藏礼物加入“个人资料／名称颜色 → 我的礼物”。选择后仅保存本机装扮快照，显示时投影自己的资料；不写账号资料或服务端礼物状态。删除礼物只清除它对应的名称或资料装扮及本地图片引用，保留另一份礼物和独立配色；关闭本地购买隐藏装扮。本人聊天引用与首页顶部礼物状态也使用同一显示投影。装扮使用负数本地媒体 ID，并提前注册本地模型／图案资源，避免把这些 ID 发去查询自定义表情。旧记录的图片路径重绑到当前 App 数据目录；缺少图案的旧收藏礼物使用空本地图案。

## 手机号显示与首页图标

手机号显示按正式／测试环境和账号独立保存，可单独开关。只覆盖本机设置页和自己资料页的号码文字，不写 TelegramUser／Postbox 的真实手机号，不调用更换号码接口，也不改变登录、通讯录、验证提示或更换手机号流程使用的号码。输入支持国家区号、空格、括号和短横线，保存为 5–20 位数字；原“隐藏手机号”开关继续优先控制显示。

本地 +888 号码按 Telegram 随包 `PhoneCountries.txt` 中的 Fragment 格式显示为 `+888 XXXX XXXX`，避免缓存的国家格式将数字分错组；短号或超长模拟号码不丢弃数字。其余国家号码继续交由 Telegram 当前格式化函数处理。设置首页、编辑号码行和个人资料页使用同一显示函数，电话操作仍使用真实号码。

专区首页入口使用 `RGSettingsIcons.localGifts` 的橙色星星图标，与现有设置图标共用 30pt 圆角方形绘制规则；副标题列出“本地会员、星币礼物与手机号显示”。专区内保留设置表单，不放插画。

## 其他界面变更

两种长按链接菜单中的“转发”接入上游新版分享界面；系统“分享”操作沿用原流程。侧栏与底栏布局保持当前设置。聊天列表的新建消息按钮与“编辑”等导航按钮使用同一中性玻璃样式，保留独立圆形。
