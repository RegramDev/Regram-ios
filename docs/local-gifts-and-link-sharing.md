# 本地星币、礼物与链接分享

当前基于 Telegram 13.1.1 / Regram b34630，测试构建号继续使用 b34631。保留现有底栏、设置导航与 Telegram 主题，仅在本机交付，尚未推送或发布。

## 入口与购买

设置 → Regram Pro → 管理与工具 → 本地星币与礼物。入口增加橙色星星图标；开关默认关闭。设置页仅保留开关、本地星币数量和保存，使用 Telegram 星币图标，不提供独立礼物目录或购买按钮。旧 catalog／owned 设置链接转到余额项，设置搜索不再展示这些旧入口。

启用并保存余额后，从 Telegram 原有的送礼物／给自己购买礼物页面选择普通礼物，或在原生收藏礼物商店选购有星币报价的收藏礼物。目录、搜索、筛选、价格图标、预览及收藏礼物确认框沿用上游，列表不再受独立页面中“图片必须已缓存”的筛选限制。目录与预览仍按 Telegram 正常流程联网加载。

普通礼物在请求付款表单前结束本地购买；收藏礼物在原生确认后、余额检查、充值和购买 RPC 前结束本地购买，详情也不预取真实付款表单。只支持整数星币报价，TON 付款在本地模式下提示不支持并停止，绝不回退到真实付款。已打开的本地确认框即使被关闭开关，也不能改走真实付款。Premium 赠送、竞拍及其他钱包操作不属于收藏礼物购买模拟。

本地购买成功扣除本地余额，保存礼物图片快照和记录，并在自己的个人资料页展示。即使从其他人的送礼入口购买，也只添加到自己的本地记录，不发送礼物或聊天消息。未加载完的图片、余额不足或存储失败均不产生成功记录。余额范围 0–9000000000000000，最多 500 份本地礼物。

## 个人资料与保存范围

本地记录和 Telegram 真实礼物只在显示时合并，不写入服务端上下文；账号没有真实礼物时也显示礼物标签。普通和收藏礼物使用 Telegram 原生礼物卡片，类型筛选与本地价格排序包含收藏礼物。收藏礼物模型、可用的图案和背景保存在本机，移除原持有人、真实 slug、钱包地址和出售等数据；不产生真实藏品所有权。

本地礼物的点击与长按进入本机详情，不进入服务端礼物操作；真实详情的左右切换排除本地记录。不能转赠、出售、兑换、升级、加入服务端收藏夹或用于服务端操作。移除不退还本地星币。正式／测试环境和账号分别保存；关闭开关隐藏记录，重新开启恢复。本地账本与图片不进入设置导出；原测试包已购买的普通礼物继续读取。

礼物页面上的余额只投影本地值，真实 StarsContext 和交易记录不变。点击这些礼物页面的本地余额进入设置编辑，不打开充值或真实钱包。大额余额使用 Int64 格式化。

## 其他界面变更

两种长按链接菜单中的“转发”接入上游新版分享界面；系统“分享”操作沿用原流程。侧栏与底栏布局保持当前设置。聊天列表的新建消息按钮与“编辑”等导航按钮使用同一中性玻璃样式，保留独立圆形。
