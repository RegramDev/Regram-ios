# 本地星币、礼物与链接分享

本轮在 Telegram 13.1.1 / Regram b34630 基线上新增本地礼物模拟，保留现有底栏、设置导航与 Telegram 主题。尚未发布。

## 入口与行为

设置 → Regram Pro → 管理与工具 → 本地星币与礼物。开关默认关闭；启用后可编辑并保存本地星币整数余额，在本地商店选择礼物、确认购买、扣除本地余额并提示成功。余额不足时不创建记录。余额范围为 0–9000000000000000，最多保存 500 份本地礼物。

本地商店读取本机已缓存的 Telegram 普通星币礼物与已缓存的图片，另提供应用内置礼物盒；没有缓存也能离线购买礼物盒。购买时把图片单独保存在当前账号的本机目录，不发起礼物、付款或图片下载请求。普通星币礼物的原生购买按钮在开启本地模式时也使用同一账本，在读取真实余额、请求付款表单之前结束本地购买；按钮标明“本地购买”，不包含升级费用。

购买的礼物显示在自己的个人资料页“礼物”标签中。即使账号没有真实礼物，也会显示该标签。本地礼物不进入礼物收藏夹、服务端排序或服务器记录；点击、长按与详情均使用本地页面。真实礼物详情中的左右切换排除本地记录。本地礼物无法调用转赠、兑换、出售或升级接口。

该模拟针对普通星币礼物，不替代 Premium 赠送、收藏礼物转售或其他付款功能。真实星币余额与真实礼物记录不变。本地记录只在自己的设备上可见，按正式／测试环境和账号分别保存；关闭开关隐藏记录，重新开启恢复。移除本地礼物不退还本地星币。本地账本和图片不纳入 Regram 设置导出。

两种长按链接菜单中的“转发”均接入上游新版分享界面；独立的系统“分享”操作保持原有行为。侧栏与底栏布局保持当前设置。

## 实现与验证

- `Regram/RGSimpleSettings/Sources/LocalGifts.swift`：纯 Foundation 账本、账号隔离、输入与容量校验、持久化及并发扣款。
- `Regram/RGLocalGifts`：本机图片快照、缓存目录读取、原生礼物组件、Telegram 主题设置页与个人资料的显示投影。
- 搜索目录、设置深链和简体中文／繁体中文／英文资源同步增加入口。
- 自动回归执行生产账本逻辑，覆盖成功购买、余额不足、非法金额、损坏记录、重启恢复、账号隔离、关闭／恢复、移除、容量与并发扣款。来源检查保护付款路径、本机图片与详情操作边界；来源检查不等于设备网络测试。

最终构建、安装身份与 IPA 校验结果在交付后补充。未执行真实账号、完整应用模拟器交互、真机或覆盖安装测试。
