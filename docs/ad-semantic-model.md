# 本机广告语义模型（b34655）

本版将训练后的 MiniRBT H256 模型随 IPA 分发，使用 Core ML 在本机判断中文推广意图。无需用户日常标注，没有消息上传、后台联网训练或自动模型下载。所有安装相同版本的用户获得相同模型；本机纠错仍然可选、按账号隔离。

## 模型与训练

基础编码器为 HIT／iFLYTEK 的 `hfl/minirbt-h256`，约 1,035 万参数、六层 Transformer。最终模型采用 FP16 权重、128 token 窗口，原文保持不变。Swift 分词器与固定版本的 BERT WordPiece 分词器对照；长消息使用重叠窗口，不能静默截掉尾部。

来源、版本、摘要、许可状态和评估值记录在 [RGAdModelSources.json](../Regram/RGAdFilter/Resources/RGAdModelSources.json)，运行说明见 [Training/README.md](../Regram/RGAdFilter/Training/README.md)。公开数据来源包括 Chinese-Spam-Dataset 和用户指定的 bayes_spam_sniper 已审核记录；tg-ad-guard-bot 的公开测试用于推广意图开发对照，没有照搬其“提及某词就删”的标签。基础模型为 Apache-2.0；公开语料未找到明确的数据集许可证，原始语料不随仓库或安装包分发，不能把基础模型许可视为语料许可。

共读取 53,762 条公开原始记录，规范化、去重、移除冲突标签，并按相似文本分组后拆分。基础训练六轮，短广告适配四轮，上下文专项适配四轮；最后一阶段另有 614 条作者编写的简繁训练行，以及独立的 55 条作者编写的域内验证输入。训练行包含简繁变体，不代表同等数量的独立真实广告。自动预测不直接作为训练真值，原始手机数据及开发报告留在忽略目录。

## 如何决定显示结果

- 先检查适用语言。这个中文检查点不能把日文插画署名或英文内容的高分当成可靠广告证据。
- 同时检查完整句子及其段落上下文。价格、付款、会员等词出现在新闻里，不应因此直接删掉句子。
- 混合消息按原始 UTF-16 范围清理有把握的广告，重算实体并独立处理按钮；不改写、摘要或重新生成正文。
- 装饰横幅只随完整推广尾栏清理：分隔线后至少两行文字独立被判为推广，所有有意义文字及其组合判断均通过，才清理其中的纯表情装饰；包含正常或未知文字的尾栏不整体裁剪。
- 整条隐藏要求完整内容得到推广判定，且有独立的推广段支持。较长推广卡片可结合标题和至少两个高置信推广段，对每个内容块逐一复核；正常正文会阻止整条删除。
- 代码、字符和链接边界始终保护。引用格式只可被整条推广判断覆盖，避免广告用引用式价目表规避处理。
- 判断在后台进行，输入、时间、缓存均有上限。超限或加载失败时保留原文，设置页会显示模型不可用。结果只作用于显示副本，聊天历史和置顶使用同一引擎，不加替换提示。

## 当前证据和限制

| 评估 | 结果 | 能说明什么 |
| --- | --- | --- |
| 公开垃圾信息测试集 6,663 条 | Precision 98.44%；Recall 40.83%；正常类 FPR 0.67% | 原始文本分类器相对语料标签的表现；标签有噪声，和频道推广意图不同 |
| 作者编写域内验证 55 条 | 30 条正常未误判，25 条推广识别 23 条 | 用于选模型，不能作为未见数据准确率 |
| 另一广告机器人的 87 条开发输入 | 48 条正常未误判，39 条推广识别 18 条 | 短暗语和陌生写法仍有明显漏判 |
| 多频道端到端开发回归 | 涵盖影视混合消息、赌场整条推广、机场卡片、短招商、科技新闻、插画来源及库存通知 | 检查保留文字、按钮和隐藏结果；这些样本参与了调优，不能据此声称通用覆盖率 |

模型阈值 0.996 是模型输出的决策阈值，**不代表 99.6% 准确率**。此前用“已过滤广告”提示替换内容的做法已移除，原文仍可通过临时显示或纠错入口查看。

尚不识别图片／视频像素或音频中的推广，不保证识别暗语、软文、未知语言和全部变体；也不能保证零误判。聊天列表摘要、系统通知暂不走此模型。开关、原文恢复和不上传消息是确定的产品行为，识别覆盖率则需要持续用独立新样本验证。开发回归通过不等于完整应用安装验证；构建、原生 iPhone 模型执行和最终 IPA 校验分别保存在本轮忽略目录的记录中。
