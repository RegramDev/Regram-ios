# 本机广告语义模型（b34656）

本版将训练后的 MiniRBT H256 模型随 IPA 分发，使用 Core ML 在本机判断中文商业推广。保留正常软件分享、开源推荐、官方免费额度及福利；无需用户先标注，没有消息上传、后台联网训练或自动模型下载。同版本用户使用同一模型，本机纠错可选且按账号隔离。

## 模型与训练

基础编码器为 HIT／iFLYTEK 的 `hfl/minirbt-h256`，约 1,035 万参数、六层 Transformer，采用 FP16 权重和 128 token 重叠窗口。Swift WordPiece 分词器保持与训练端一致，长消息不能静默截掉尾部。Core ML 的 ANE 概率对照超出原有误差容限，因此本版使用后台 CPU 推理及共享缓存；耗时按完整消息实测，不把缓存命中耗时当作冷推理速度。

来源、版本、摘要、许可及指标见 [RGAdModelSources.json](../Regram/RGAdFilter/Resources/RGAdModelSources.json)，流程见 [Training/README.md](../Regram/RGAdFilter/Training/README.md)。公开来源包括 Chinese-Spam-Dataset、bayes_spam_sniper 的已审核记录；tg-ad-guard-bot 的 87 条公开测试作为推广意图开发对照。基础模型采用 Apache-2.0；公开语料未找到明确的数据集许可证，原始语料不随仓库或安装包分发，基础模型许可不等于语料许可。

原有训练读取 53,762 条公开记录，规范化、去重、移除冲突标签，并按相似文本分组后拆分，经过 6 + 4 + 4 轮训练。本轮从经用户授权的本机导出读取 223 条快照，来自 16 个匿名来源组：82 条正常、44 条纯广告、95 条混合消息、2 条需人工媒体判断的记录。逐条按商业推广意图审核完整片段，没有把自动检测范围直接当成真值。

24 条消息所在的 6 个来源组未加入本轮训练，其余 199 条记录中有 197 条可用于文字训练。因为留出结果参与了开发判断，这 24 条也只是开发留出，不能称为最终未见测试。新增适配阶段分别运行 6、4、4 轮，选用各阶段第 6、1、1 轮的检查点；额外 4 轮候选因域内验证召回退步未采用。最终适配含 6,988 条简繁及窗口扩展训练行和 7,899 条原训练集回放，行数不等于独立真实广告数。手机原文、检查点和报告均保留在忽略目录。

阈值校准仅使用原公开验证集和 55 条作者编写的域内验证输入，仍要求公开验证 precision ≥ 98.5%、正常类 FPR ≤ 0.5%，再优先考虑域内正常保护和召回。将高分区域的网格细化到 0.00001 后，选定片段阈值 **0.99919**；测试集只在选定之后计算指标。阈值是模型输出的决策边界，不是准确率。

## 如何决定显示结果

- 中文片段可独立识别；外文片名和标签导致整条语言判断偏移时，保留外文正文，仅检查其中的中文片段及按钮。
- 句子同时参考空行分块及相邻正文。正常文章中的价格、上线状态、新闻服务说明不能仅因孤立高分被删。裸链接和账号没有独立推广语义，不单独按模型分数删除。
- 混合消息按原始 UTF-16 范围去掉广告，重算实体和按钮；不改写、摘要或生成正文。
- 有明确分隔线的商业尾栏，需要有独立高分推广文字，且没有正常或未知文字；纯装饰及裸联系方式可随完整尾栏清理。两个已删除广告段之间的装饰表情也随之移除，正文中的字词、代码、引用和独立目标保持保护。
- 整条判定要求完整文字通过片段阈值，或满足更严格的联合证据结构：完整文字及每个有意义的空行分块均 ≥ 0.99，且至少两个分块 ≥ 片段阈值，没有独立正常正文或受保护代码。后一分支只适用于整条卡片，不能放宽单句删除阈值。
- 实际代码受保护；短 ASCII 优惠码格式和引用式价目表可随完整推广卡片隐藏。媒体人工标注只匹配被审阅的消息及附件快照，不泛化到其他无文字图片。
- 纯广告附图及同一相册中无独立说明的附件随整条广告隐藏；正常说明、按钮或人工正常／待定媒体标注会阻止连带删除。不按相邻关系删除独立图片。
- 频道、普通群、超级群、置顶和主页预览使用同一判断。主页从本地最近 50 条逐步寻找正常预览，保持排序、草稿和未读数。判断在后台运行，有输入、时间和缓存上限；首屏可能先显示原文，完成后刷新。

## 当前证据与限制

| 评估 | 结果 | 解释 |
| --- | --- | --- |
| 公开文本测试 6,663 条 | Precision 98.11%；Recall 33.73%；正常类 FPR 0.67%（TP 1,144、FP 22、FN 2,248、TN 3,249） | 原始分类器相对噪声垃圾信息标签的指标，不是应用广告覆盖率 |
| 作者编写域内验证 55 条 | 正常 30/30 保留，推广识别 22/25 | 用于模型／阈值选择，非未见测试 |
| 外部机器人开发输入 87 条 | 正常 47/48 未判广告，推广识别 12/39 | 仅文字分数，未套用语言和上下文投影保护；陌生短暗语仍有明显漏判 |
| 新手机文字开发回归 221 条 | 正常正文未损失；44/44 纯广告隐藏；95/95 混合消息广告完整去掉；按钮无误删或残留 | 样本已审阅并参与调优，不代表未知频道效果 |
| 合并旧版后的开发回归 322 条 | 270 条含正常正文均保留；174 条含广告文字完整清理；52 条纯广告隐藏 | 按完整广告范围计分，只删联系方式也算失败；两条纯媒体人工标注另由桥接／存储检查验证 |

实际 iPhone 16 Pro（iOS 27.0.1）运行同一模型、分词器及投影检查器：322 条结果与 macOS 一致，100 条转换输入对照通过；整条消息判断中位约 67 ms、P95 165 ms，模型冷加载约 51 ms。该数据来自含缓存复用的诊断程序，不是完整应用滚动帧率或全冷推理基准。

本轮将结果、耗时、转换对照、真机模型运行、完整 Release 编译和 IPA 验收分别记录在 `build-input/ad-filter-34656/`。自动预测不会成为后续训练真值。原文仍保存在消息数据库，可通过临时显示或纠错入口查看，不加入“已过滤广告”占位提示。

尚不识别图片／视频像素或音频中的广告，也不保证识别未知语言、暗语、软文和所有变体。系统通知不参与此次投影。开发样本零误删、零残留不能推导出实际使用零误判；新版本仍需持续用独立新样本验证。
