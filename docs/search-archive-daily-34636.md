# b34636：消息搜索、归档与独立每日任务

2026-10-25，基于已发布 b34634 的源码，合入本轮消息、分组及归档修正，并处理 b34635 本地验证包的搜索清除反馈。用户最初要求仅交付本地包，随后明确授权修复后发布；b34635 未公开发布，正式版本为 **13.1.1 / b34636**。

## 用户可见行为

- 长按头像进入「查看此人本群所有消息」，使用 Telegram 原生搜索栏和分页结果列表，按关键词查询当前群组或话题并返回原消息。输入框内清除按钮和旁边的关闭叉都可恢复全部发送者消息；关闭叉同时收起键盘。清空会立即取消旧查询，过期结果不能覆盖新列表。
- 分组标签的本机开／关选择保存在账号偏好中，服务端的非会员标签值不再把它关闭。服务端没有颜色时使用稳定的本机颜色。
- 社群折叠、展开及临时隐藏会话时保存归档归属。手动归档／取消归档的未完成操作跨请求保留，旧置顶查询或实时置顶通知不能覆盖本机选择；服务端确认后恢复接受后续正常同步。
- 设置搜索「归档设置」打开实际归档设置页。用户撤回的「文件夹显示归档」问题保持原有行为。
- 定时发送 → 重复菜单新增独立「每日首次启动」。选择一次后，按账号保存在本机，从所选日期开始每天首次打开 Regram 时静默加入普通发件队列，当天不重复，不补发错过日期。支持编辑、删除、立即发送，以及用户明确选择后从已有服务端定时消息转换。所选时刻不用于这一模式。
- 会员原生「每日」「每周」及其他周期的文案、权限与服务端调度保留，仍可在 App 未打开时执行。独立本机标识不会占用 Telegram 的正数重复周期。b34635 已登记的本机任务只迁移标识，保留开始日期和已发送日期；不迁移未登记的会员任务。

## 原因与实现

玻璃搜索框外侧关闭控件把点击转给 `SearchBarNode.cancel`，原页面只连接文字变化回调。现接入关闭回调，使用原生文字 setter 发出清空更新，并即时重载空查询；清空不经过输入防抖。

本机每日任务此前使用了原生每日周期值，可能接管会员的每日重复。现使用独立值并保留原生周期菜单项；捕获、编辑、转换、状态显示和已登记旧任务迁移使用同一标识。新任务的本地列表项不进入网络发件队列，真正的当日消息与日期去重标记在同一事务提交。会员正数周期不被本机捕获或自动转换。

分组与归档修正使用账号 Postbox 偏好保存明确标签选择、最近归属、交互修订号和未完成的归属确认。社群临时排除不再丢掉归档信息；归档网络请求对临时失败重试，并仅确认对应的当前归属。
