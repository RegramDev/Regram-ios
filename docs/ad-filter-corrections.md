# 频道广告片段过滤与本机纠错

本轮基于已发布的 13.2 / b34652，构建号为 b34653。入口为「Regram Pro → 隐私与过滤 → 消息过滤器 → 自动广告过滤」；消息长按菜单提供「纠正广告过滤」，已清理的消息提供「查看原文 / 纠正过滤」。

## 自动处理

所有安装相同版本的用户共享 `RGAdPolicy.revision` 对应的内置规则。本版保守识别同时包含推广措辞和跳转目标的少数明确广告模板，以及明确的广告合作按钮。按段清理文字、独立处理按钮并重算 UTF-16 实体位置，保留其他正文、搜索入口及图片／视频。引用、代码、反诈提醒、新闻报道不按内置推广规则删除。普通资源链接不会因存在网址而被删除。

处理只生成聊天历史的显示副本，不修改 Postbox 或服务端消息；副本携带原文引用，长按复制、编辑及纠错使用原文。纯广告文字显示一个可找回原文的简短提示。旧关键词／隐藏成员规则仍生效；单会话关闭规则、临时显示隐藏内容也会停用片段清理。首屏先展示原文，后台完成判断后更新；不把网络或磁盘读取放进消息排版。

本版的自动清理范围是普通频道消息的正文、说明和 inline buttons。聊天列表摘要、置顶栏、系统推送以及媒体画面中的广告不在这一版处理；富文本文档、秘密聊天、一次性或受保护内容不参与样本采集。内置规则覆盖有限，未知广告会保留。本版未接入此前仅以合成样本训练的实验模型，也不宣称零误判或已达到通用广告识别能力。

## 可选纠错

打开纠错页只生成草稿。初始红色区域来自自动建议，只有「确认并保存」才形成已审阅样本；未标记的文字视为正常，按钮和媒体默认待定。原文不可编辑；用户可框选「正常／广告／待定」、一键全正常或全广告，并预览结果。选择自动对齐完整字符、链接及自定义表情边界。媒体只记录类型与标签，本版不因此隐藏或保存媒体文件。

样本按账号保存在账号目录的 `regram-ad-samples-v1`，排除系统备份；原文快照不可变，消息编辑或媒体替换产生新的快照。相同快照重开可继续编辑。确认后的长广告片段仅在同一频道精确复用；按钮按标题及完整目标复用；正常或待定标注阻止冲突学习。删除记录后取消从它派生的偏好。最多保存 1000 条，不自动淘汰用户记录；读取损坏数据会报错，不覆盖原文件。

## 公共版本改进

导出为版本化 JSONL：`schemaVersion: 1`，`offsetUnit: utf16`；`input.text` 是原文，`spans` 采用左闭右开范围，`normal/ad/uncertain` 分别对应正常、广告、待定；按钮通过原始行列 ID 独立标注。`sourceGroup` 由本机随机盐与来源 ID 派生，用于分组评估，不导出原始账号／频道 ID。原文和链接本身仍可能含个人信息，所以导出前明确提示用户核对，只有主动分享后才离开设备。

公共规则或模型应在自愿提供并审核的样本上改进，通过按频道和广告模板分组的留出集检验，再随新版 IPA 分发给所有用户。自动预测不能直接充当训练真值；待定区域不作为负样本。重点评估正常内容误删、广告残留、按钮误删、混合消息正文保留和设备耗时，不能用整体准确率掩盖误删。私人纠错不会自动变成全局规则，应用没有自动上传、后台训练或远程模型订阅。

## 验证

`swift test --package-path Regram/RGAdFilter` 覆盖段落裁剪、按钮独立性、链接目标规范化、引用和反诈文本保留、Unicode、账号隔离、编辑快照、持久化、导出及损坏数据。完整 arm64 Release、最终 IPA 与设备验证结果记录在本轮忽略的 `build-input/ad-samples-34653/` 中；以实际完成记录为准。
