# 本地个人资料扩展

本轮以 13.1.1 / b34631 为基线，已正式发布 [13.1.1 / b34632](https://github.com/RegramDev/Regram-ios/releases/tag/v13.1.1-b34632)。界面优先沿用 Telegram 对应组件，设置仍位于 Regram Pro → 显摆一下。

本文保留 b34632 的实现与交付记录。当前入口和后续行为以 [b34633 更新](profile-notifications-34633.md)及[功能清单](features.md)为准。

## 功能

- 本地收藏礼物支持置顶／取消置顶：长按礼物或从原生详情右上角“更多”操作。置顶会恢复显示；隐藏会取消置顶。数量沿用 Telegram 配置，同时计算真实礼物已占用的位置，最多保留 12 个本地置顶记录。头像周围使用上游礼物组件的排布、动画及背景星光；正在作为资料装扮使用的礼物按原生规则不重复显示。点击装饰打开原生详情，删除和关闭本地购买同步刷新。
- 本地评级独立开关，支持 −999 至 999 的整数。正数、零与负数均由 Telegram 原有评级及说明组件呈现，负数采用低信用度样式。只投影自己的个人资料快照，不改服务端评级或真实待更新评级。
- 本地 TON 资料卡使用 Telegram 原生余额入口、模糊背景、卡片和礼物贴纸播放。启用后在自己的个人资料页点击余额打开，数值跟随本地 TON 账本，包括零余额。最多六份置顶本地收藏礼物作为装饰。它没有收款地址，二维码入口显示本地说明，“它是如何运作的？”打开 Telegram 的钱包介绍，不发起转账。关闭后恢复真实资料卡，真实钱包及交易记录不变。
- 手机号编辑拆为区号与号码两个输入框，旧值按 Telegram 国家区号拆开，+888 单独保持 Fragment 分组。仍保存完整数字，显示继续使用同一 Telegram 格式化路径。
- 表单将 Telegram 容器提供的键盘高度计入可用空间，聚焦时滚动输入行并保留保存操作，支持系统键盘完成操作；保存后收起键盘。
- 隐藏底栏时的返回与二维码组合按钮使用 Telegram 的位图着色方法，将导航栏颜色写入实际图像像素；避免 `ASImageNode` 直接显示 `CGImage` 时丢失 UIKit 图片的 tint 信息，导致白底仍显示白色符号。组合按钮与更多／搜索动画图标随原生导航玻璃刷新，主题与语言切换沿用同一更新路径。

旧账本缺少的新字段使用关闭／未置顶默认值，原余额、礼物、手机号与装扮保留。各正式／测试环境及账号独立保存。本地资料卡受本地礼物模式开关控制，评级和号码显示各自独立。
