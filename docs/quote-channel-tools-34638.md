## 引用选中文字

用户提供的 b34637 崩溃日志使用匹配 UUID 的 dSYM 还原到 `ChatController.swift` 的 `.quote` 分支：菜单点击后直接以选区范围截取 `message.text`，引发未捕获的 Objective-C 字符串异常。日志不含原消息、选区和设置状态；本轮用合成消息验证接收时盘古空格能够触发该越界。

普通文字气泡的选区菜单原先绕过了 `getCurrentTextSelection` 的盘古反向映射。现在将该菜单的 UTF-16 选区转换回原文，并核对选中内容。消息在选区打开期间被编辑、显示替换文本与原文不一致、空选区、无效范围或拆开代理对时，退回普通回复。控制器在读取当前消息后再次检查范围及文字，避免旧选区导致闪退或引用到其他内容。格式和实体继续来自消息原文；结构化富文本沿用原有引用路径。

## 消息动作设置

两个开关位于“Regram Pro → 聊天与消息 → 消息动作”，默认关闭，均纳入全局设置搜索、深链定位、备份及恢复，包含简体中文、繁体中文和英文。

- “删除消息自动一键三连”：打开管理员删除消息面板时，同步初始化可用的举报、删除发送者全部消息与回应、封禁选项。沿用原生权限判断，不选择本人，其他操作模式保留原样。用户仍通过原生面板确认，可更改勾选；面板重绘不会重新覆盖用户选择。
