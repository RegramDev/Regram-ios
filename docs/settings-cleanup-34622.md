# b34622 设置与兼容清理

聊天顶部工具栏、聊天内搜索框置底、聊天内搜索结果从底部开始已移除，包括实际布局和结果顺序逻辑、偏好访问、分类备份、搜索索引及设置入口。旧 Regram 深链无法重新打开这三个控制项；旧备份中的相关键会被忽略。聊天内搜索使用原生顶部搜索框及结果顺序，全局搜索倒序仍由独立设置控制。

「聊天与消息 → 消息动作与显示 → Inline 机器人」集中提供自动查询开关、用途说明和只读规则。规则按机器人分组，以多行等宽文字展示完整表达式；元数据更新后，已打开的页面也会刷新。查询仍只发送单独输入的匹配 HTTP(S) 链接，保留输入框的原始文字。

「输入与发送 → 盘古之白」集中提供接收、发送、编辑三个独立开关，与 Nagram 的三个维度一致。发送开关继续使用原有保存值，按聊天覆盖的设置继续有效；输入设置页不再重复放置接收和编辑开关。

Swiftgram 兼容已移除：不再迁移 `sg_` 偏好、SG 图标名和旧 Postbox 界面设置，不再解码 `sg`／`sggh` 配置；构建输入要求 `rg_config`。不再注册或接收 `sg:`、`tg://sg/`、`sgdebug` 及购买／恢复旧跳转。现有 Regram 的 `tg://rg/`、`rg:`、`regram:` 和按当前应用协议生成的链接继续使用 RG 路由。已保存的 RG 设置、安装身份、App Group、钥匙串及数据容器未变。
