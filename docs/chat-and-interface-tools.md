# 聊天与界面增强实现记录

本轮范围为历史对照 F01–F29、F31–F32、F35–F36；用户明确排除 F30 格式工具栏、F33 iCloud 同步和 F34 登录会话备份。独立分支保留之前的本地置顶修复。新增操作与配置接入现有 Regram 分类、全局搜索、设置深链和分类备份。

已通过 Xcode 27 的 `//Telegram:Regram` arm64 Release 完整构建，包含主应用和六个扩展；40 项本地回归通过。用户已确认本轮测试包验证通过并同意推送主线，小问题按要求留待下个版本处理；逐项设备和场景以单独记录为准。

## 入口与行为

- 聊天与消息 → 消息动作与显示：顶部快捷工具、单击菜单、取消置顶确认、刷新跟随最新消息、聊天内搜索置底、聊天内搜索倒序、自动 inline bot 查询及规则查看。
- 聊天与消息 → 聊天列表：收藏夹／归档预览隐藏、隐藏对方活动状态、底部全局搜索倒序、列表新消息位置、Community 合并及头像行为、四模式横滑、下拉直接进入归档。
- 聊天与消息 → 分组：分享面板文件夹、标签图文方式、未读数显隐、非全部分组的归档入口、按账号固定启动文件夹。
- 输入与发送 → 输入设置：发送／编辑／接收盘古空格、选中文字菜单定制。格式工具栏保留原开关、布局和行为，不新增模式或迁移。
- 外观与界面 → 资料设置：自选群管理项；权限和可见项目仍由现有群资料逻辑决定。
- 隐私与过滤／动态：独立顶部动态及头像动态入口、权限提醒显隐；隐藏提醒不授予系统权限。
- 媒体与链接 → 播放：画中画上滑手势。裁剪边缘保持缩小直接接入原裁剪器。
- 固定操作入口：群／频道资料页添加到文件夹、联系人双向标记、底栏隐藏联系人后的设置入口、邀请链接页批量撤销、搜索框链接结果、链接预览图片进图库。

全局结果倒序在底部搜索栏模式下生效；聊天内结果倒序单独控制。

自动查询机器人默认关闭。开启后只把单独输入的匹配 HTTP(S) 链接交给对应机器人查询，不提交链接旁的草稿文字，输入框保留原链接。批量撤销需要用户确认，排除主链接、永久链接、已撤销链接及其他管理员的链接，并显示部分失败结果。
