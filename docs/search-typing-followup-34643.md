# b34643：顶部搜索快速输入复查

2026-10-31，用户反馈 b34642 顶部搜索在中英文快速输入时仍有卡顿。上一轮减少了输入回调触发的查询和日期解析，但没有覆盖结果列表的同步排版及绘制。

## 原因与修改

`ChatListSearchListPaneNode` 在查询文字改变时把结果更新标记为 `firstTime`，随后给列表事务同时设置 `Synchronous`、`PreferSynchronousResourceLoading` 和 `PreferSynchronousDrawing`。生产 `ListViewImpl` 因此会在主线程创建和排版结果行，并在提交时强制绘制，继续占用键盘输入所需的线程。输入防抖不会改变已返回结果的这条执行路径。

本次对事务条件做最小修改：非空查询的结果使用既有异步列表排版和绘制；空查询初始呈现、下载页策略和选中／展开动画保留。上一轮的 120 毫秒输入合并、后台日期解析和立即清空继续保留。
