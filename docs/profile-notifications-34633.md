# b34633：装扮同步、礼物升级与通知入口

版本为 13.1.1 / b34633，沿用 Telegram 的界面组件、Regram 的现有布局及安装身份。

- 聊天引用中的本人名称、引用色条和背景图案使用与个人资料一致的本地名称装扮；浅色和深色配色交由 Telegram 原生组件处理，其他用户的配色保持其自身数据。
- 聊天列表顶部同步个人资料设置的本地礼物状态。先准备本地动画资源再刷新；切换、清除、删除关联礼物或关闭本地装扮后，显示随之更新。
- 恢复原生礼物购买页的转售浏览路径：转售分类、售罄且有转售的礼物继续进入原生转售列表，星币／TON 购买仍由本地购买开关控制。
- 本地限定礼物可在原生详情中预览和升级。使用 Telegram 的升级目录、报价和已缓存的模型／背景／图案，只扣本地星币；原购买记录原位更新，保留日期、可见性和本地标识，重复的旧确认不会再次扣款。旧版已购礼物也会重新读取可用升级预览。
- 实验性通知恢复迁至「设置 → Regram Pro → 通知与提醒」，保留原共享键和旧开启状态；移除调试页重复开关，支持搜索、定位链接及通知类别的备份、恢复和重置。
- 同时包含上一份本地测试包的[18 项现有功能修复](functional-fixes-20261024.md)，涉及富文本工具、翻译、分享、回车发送、消息保留、搜索失败与设置刷新。

本地装扮、礼物购买和升级只修改本机保存的数据，不改变真实订阅、余额、服务端礼物所有权或其他用户看到的资料。礼物目录、转售列表、升级预览和对应资源仍按 Telegram 正常流程读取。

专项回归覆盖生产装扮投影、原生配色／状态编码、本地升级扣款和持久化、旧确认重复提交、通知旧键兼容与事务后刷新、搜索和设置链接。完整构建及发行包按仓库的 arm64 Release、六扩展、严格签名和匹配 dSYM 流程生成；本轮命令、源码摘要、结果及发布核验记录保存在忽略的 `build-input/` 中。缓存跨版本保留，构建完成后关闭空闲 Bazel 服务。
