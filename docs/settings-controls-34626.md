# b34626：分类横栏、图标与控件颜色

本轮保留 b34625 的九类入口与分类内设置，不改偏好和备份格式。用户授权修复后构建 b34626，推送 GitHub 并同步 Release；沿用此前跳过测试的要求。

## 分类横栏

聊天与消息、媒体与链接改为复用聊天文件夹使用的 `HorizontalTabsComponent`，由 Regram 自有导航内容节点承载。横栏高度固定 56 pt，内部可操作区域高 44 pt，保留左右安全边距；内容处于父容器的点击范围内。横栏沿用组件的选中、主题及长文本横向滚动，关闭重排序与抬起效果。

页面标题保持普通标题；选中状态在独立主线程订阅中更新，不再依赖原标题标签的异步更新。有效点击交给状态源去重，不用滞后的渲染选中值忽略快速点击。原三／四个标签与设置深链的初始标签继续使用同一索引；横栏不增加返回层数。生命周期内复用横栏，控制器释放时取消订阅。

## 图标取舍和对齐

- 隐私组整组取消装饰图标，移除重复的锁和气泡，保证六个入口标题左边缘一致。
- 链接预览和 LLM 基础选项所在分组以文字为主，不重复添加图标。
- 字体、应用图标、截图标记、语音识别、消息总结、网络／诊断、备份／更新、底栏和菜单编辑器使用匹配用途的系统符号。首页分类保留既有原生分类图标。
- 系统符号使用 30 × 30 pt 画布和统一背景样式，按实际非透明图形边界居中；多行说明继续换行，图标改为整行垂直居中，不使用固定顶部偏移。

这些符号由 UIKit 绘制并缓存，不新增 AI 生成图或图片资源包。图标缺失时允许文字入口正常显示。

## 控件颜色

链接预览页的 `UISwitch` 不再接收 Telegram 自绘开关的深色 `handleColor`，恢复系统滑块／材质；开关启用色和边框继续来自 Telegram 主题。UIKit 页面已有的主题、输入框、说明、禁用态和重置动作沿用原语义颜色。

书签侧滑操作的文字由 UIKit 渲染为白色，原先直接把可能为白色的主题强调色当背景。现在保留主题色调，在必要时降低背景亮度，使白色文字与背景的对比度至少达到 4.5；删除操作的角色不变。不修改全局 `UIAppearance` 或上游主题。
