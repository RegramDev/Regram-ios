# b34648：底栏崩溃与 13.2 兼容性复查

基于已交付的 13.2 / b34647（应用源码 `9c3a82b02ce4b995c0928d5735ec92489c17f52f`，含文档的工作树基线 `22edf7f2d4`）修复用户提交的崩溃，并复查新上游与 Regram 的兼容路径。本轮使用 `fix/tab-selection-crash-34648` 分支，保留已有 rules_apple 兼容补丁和其他工作树的改动。原始崩溃日志与本地验证文件不提交。

## 崩溃原因与修复

日志来自 13.2 / b34647。TelegramUIFramework 的 dSYM UUID 与崩溃中的镜像一致；主线程前四帧定位到 `TabBarControllerImpl.loadDisplayNode()` 的标签选择回调、`TabBarControllerNode.updateImpl` 创建的动作回调和 `TabBarComponent.View.onTabSelectionGesture`。越界发生在旧源码 `TabBarController.swift:217`。

底栏组件按 UITabBarItem 身份比较，动作闭包不参与相等判断。设置关闭联系人、通话后，显示的聊天／设置按钮可能继续保留旧动作闭包；设置仍捕获下标 3，而控制器数组已从四项减为两项。直接用该下标更新页面布局会触发 Swift 数组越界。相同数量的重排也可能打开错误页面。

- 选择、长按、双击与菜单回调在执行时按按钮对象身份查找当前下标；已移除的按钮不执行动作。
- 控制器入口使用实际控制器数组验证下标，避免拿尚未刷新的显示列表作为边界。
- 一次选择保存目标页面身份；重入布局和异步 ready 完成后重新按身份定位，防止期间重排／删除导致错选。
- 重建根标签列表会取消尚未完成的页面选择，避免移除再加入后触发旧任务。

回归直接编译并执行生产组件工厂、控制器事件回调和重建前置逻辑，使用真实 SwiftSignalKit，隔离 UIKit 边界。覆盖四项变两项、等长重排、移除按钮、无效下标、重入布局、延迟就绪、取消、长按菜单、双击、当前页面回顶及连续开关。旧版本按相同路径复现数组越界。

## 原生照片发送

13.2 新增的 ChatMediaSend 绕开了旧照片发送实现。编辑后照片在新路径固定以 0.6 JPEG 质量编码，没有读取 Regram 的照片压缩质量；粘贴 UIImage 的回退和异步预处理路径也直接把点尺寸当像素尺寸，且没有完整保留原有粘贴图片的 HD／最高质量策略。

- 新原生编码器读取 Regram 现有压缩质量设置，原相册资源读取路径保持原有处理。
- 粘贴图片在预渲染、异步准备和直接发送路径均保留最高 JPEG 质量及 2560px 上限，按 UIImage.scale 换算像素；裁剪后尺寸继续以编辑元数据为准。
- 保留贴纸标记、文件发送、视频／Live Photo 及动画照片的原有分流。

回归编译并执行生产编码、异步准备、直接图片分支和渲染尺寸决策，图像及压缩调用使用隔离边界，覆盖四档质量、1x／2x／3x 图片、HD、裁剪和贴纸。旧版本分别复现压缩质量设置未生效与粘贴图片分辨率损失。

## 扩大检查的范围

以官方 13.1.2 基线到 13.2 的变化，与 Regram 自有补丁生成 210 个共同修改源码文件的清单；重点复查底栏与联系人生命周期、搜索取消、状态重放和删除确认、防撤回与机器人排除、本地置顶／归档、消息过滤与已读、文件组父容器、原生 HLS 首帧及播放器复用、相机分支、照片发送与设置恢复。

现有功能检查覆盖设置备份恢复、翻译／总结、通知、搜索、媒体保存、贴纸、本地资料、邀请、导航和过滤等生产路径；另外执行上游 HLSPlayback 主机测试与真实 Postbox 缓存清理测试。HLS 的时钟／网络为上游模拟环境，Postbox 使用临时文件及隔离数据库，均不使用真实账号。

此范围是一次上游兼容性与回归排查，不代表穷尽所有设备、消息内容或服务器配置。UI 回归没有替代真实 iPhone 上的手势、相机、照片编解码、网络播放和覆盖升级验收。

构建与包验证结果在完成本轮交付后补记；应用源码提交与后续纯文档提交分别记录。
