# Regram 近期更新记录

本文汇总截至 **13.0 / b34624** 的主要功能和修正，按构建号由新到旧排列。完整可用范围见[功能清单](features.md)，中文／英文介绍见根目录 README。以下是源码与交付记录，不代表每项都已真机验收。

## b34624：设置界面、原生底栏搜索与返回绘制优化

用户于 2026-10-21 确认最终测试包本机测试通过，并授权公开发布；公开状态与下载见 [GitHub Releases](https://github.com/RegramDev/Regram-ios/releases)。未提供逐项设备测试场景或量化帧率记录。源码已合入 `master`；构建来源、包校验值及验收边界见[集中记录](settings-appearance.md#b34624-构建与交付记录)。

- 设置及 Regram 新增功能页统一 Telegram 分组、主题和 glass 导航；字体、截图标记、消息过滤、书签、作者消息、共同群组、编辑历史与消息总结等页面保持原有操作。共同群组列表补充头像、状态及主题更新。
- 底栏搜索在「显示项目」统一开关，默认关闭；复用 Swiftgram 原生右侧按钮和展开输入框，聊天／联系人／设置搜索当前页，通话页沿用新通话选择器。搜索不是可排序标签；原独立导航项偏好、顶部搜索、旧配置、备份和深链继续兼容。
- 显示项目保持紧凑单行，按字宽分配空间；底栏自动宽度随导航项数量收紧，保留手动宽度。关闭搜索或隐藏整栏时清理已激活的底部输入状态。
- 设置页右划返回聊天为整屏快照指定固定阴影轮廓，减少动态阴影计算，保留跟手、视差、取消与完成动画；尚未测量设备帧率。
- 保留 b34621–23 的置顶重同步、分组与手势、JSON 导入、别名清理和原生设置焦点修复；底栏旧搜索深链定位新的显示项目行，并使用原生行高亮。
- Xcode 27 完整 arm64 Release、主应用／六扩展、12 份匹配调试符号检查通过；独立包与源码审计 35/35 通过。本轮按要求保留构建缓存，仅关闭空闲 Bazel 服务。
