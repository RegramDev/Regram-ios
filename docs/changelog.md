# Regram 近期更新记录

本文汇总截至 **13.0 / b34618** 的主要功能和修正，按构建号由新到旧排列。完整可用范围见[功能清单](features.md)，中文／英文介绍见根目录 README。以下是源码与交付记录，不代表每项都已真机验收。

## b34618：共同群组发言与返回动画

- 统一声明 Xcode 27 工具链，与本地及 CI 实际打包配置一致。
- 隐藏底栏时，设置返回聊天采用跟手滑动、聊天视差及取消回弹，处理旋转、导航中断和过期动画回调。
- 个人资料「更多」增加共同群组发言独立页面：跨群分页合并、按群筛选、暂停继续、失败重试及原消息／话题跳转。
- 区分搜索失败与无结果，保留已加载内容；遵守消息过滤及剧透显示设置，不识别匿名或频道身份发言为个人发言。
- 分页及返回状态回归通过，完整 Xcode 27 arm64 Release 构建及主应用／六扩展包校验通过，身份及权限与 b34617 一致；尚未进行新功能真机验收。

## b34617：搜索底栏恢复与返回手势

- 搜索或工具栏临时隐藏底栏后，恢复时重建玻璃效果视图，覆盖之前仅处理空内容恢复的遗漏；普通可见状态重排继续复用组件。
- 隐藏底栏时，设置首页支持从内容区域横向右滑返回聊天，不再局限屏幕最左边缘；排除按钮、编辑框及横向滚动区域，保留编辑、头像展开和导航层级判断。
- 状态回归重现旧版搜索恢复未重建的问题；新逻辑通过搜索、工具栏、显隐和延后恢复检查。返回手势通过方向、控件避让及真实 UIKit SDK 类型检查。
- 已完成 arm64 Release 构建、主应用及六扩展的包结构／签名／调试符号校验，并与 b34616 比对安装身份和权限。新修正的设备视觉与手势验收尚未记录，不改变 b34616 的既有验收记录。

## b34616：图标切换误报

- 修复桌面图标已经改变，应用却显示「无法切换图标」并仍选中默认图标的问题。
- 以系统成功回调同步选中项及 Regram Pro 图标，再延后校对系统读值；应用暂不活跃时排队，回前台继续。
- 成功路径不弹应用自建的失败提示，真实失败仍保留处理和日志。
- 图标回归包含成功回调后系统读值滞后、恢复默认、排队及失败场景。完整 arm64 Release、包与公开下载校验通过。
- 2026-10-15：用户确认本轮真机验收通过，适用于此次实际测试的设备与场景；此项为用户反馈，与主机构建及合成回归记录区分。

## b34615：网络策略、导航及撤回标记

- DNS 统一为内置 HTTPS、系统、自定义 DoH 三种模式，解决重复系统 DNS 开关冲突。
- IP 策略扩展为自动、优先 IPv4／IPv6、仅 IPv4／IPv6，约束原生 DC 与代理候选及连接；新增解析兼容、请求合并、取消和缓存处理。
- 自定义解析接入备用 DC TXT，保留签名和时效校验；支持关闭额外备用地址发现，诊断展示实际 A／AAAA 与策略结果。
- 修复实时活动点击误用网页协议导致进入空白页，调整灵动岛展开布局及版本显示。
- 修复隐藏底栏后设置返回聊天，以及取消隐藏仍要重启才能恢复的问题。
- 已撤回消息标记支持图标、文字或隐藏，自定义文字与颜色，纳入设置搜索、深链及备份，并刷新已显示消息。
- 加强图标切换协调；其成功回调误报问题继续在 b34616 修正。

## b34613／b34614：后台下载与实时活动

- 域名代理保留多个地址，失败或四秒无响应后轮换，重新握手并短时记住成功地址。
- 更新使用系统后台下载，保存并恢复任务，继续严格验证资产。
- 增加锁屏与灵动岛更新活动，显示下载、校验、签名及待安装状态，支持开关和取消收尾。
- 实时活动与登录欢迎页采用 Regram 图片，补齐实际构建生成的实时活动声明。
- b34613 用于本地测试，b34614 作为后续更新包；两者版本号区别不代表两套功能。

## b34610–b34612：消息工具与界面

- 修复书签点击跳转崩溃，书签入口移到设置首页「我的收藏」下方；检查相关页面主题色与图标。
- 新增独立接口的大模型总结：默认关闭、时间范围获取、单条／多选、上传前确认及内容上限。
- 新增消息截图与贴纸包 ZIP 备份；截图最终收敛为单条，头像左侧、名字及正文右侧上下排列，无气泡背景和重复姓名。
- 底栏恢复上游组件及交互，保留布局设置；自动宽度兼顾内容、点击间距和完整居中，移除单独色调强度调节。
- 增加 DNS／IP 设置及独立测试页，后续在 b34615 完善严格地址族与解析行为。
- 优化视频右上角菜单构造及深色图标，补充复制 DC／总结结果等操作的即时反馈。

## b34607–b34609：书签、分类与单包发行

- 增加按账号保存的消息书签、标签及本机群名称备注。
- 设置细分为九类，输入及网络参数独立归类；DC1–DC5 测试进入二级页，复制结果精简为平均 Ping。
- b34608 收敛为一份 Regram IPA，恢复既有数据目录、共享设置和应用锁范围；不再维护多身份资产选择。
- b34609 补齐通知服务扩展过滤权限声明。声明不等于设备获得授权，仍需实际签名和描述文件支持。

## b34604–b34606：播放器、更新及消息历史

- 视频控制移至底部，更多菜单承载小窗、倍速及画质；修复照片画质数值与滑杆位置不一致。
- 新增自动显示剧透开关，接入文字、媒体和图库说明。
- 修复清除全部数据时启动白屏及确认弹窗消失，延后至界面激活后确认。
- 更新提示区分发现新版、准备完成及失败，恢复缓存不再重复提示下载；Pro 图标随 App 图标刷新。
- 修复底部分组切换预布局错位，以及聊天内 @ 跳转按钮因已读同步及待处理计数重新出现。
- 图片编辑历史支持旧图保存、预览及缩放，设置每版和每条消息图片容量上限，排除不适合持久保存的媒体。

## b34600–b34603：语音、链接及设置导航

- 自定义语音／圆视频识别，支持接口测试及识别后翻译；加入链接预览修复和应用内网页翻译。
- 更新加入 TrollStore 路径；证书与描述文件同时选择，之后输入密码验证和保存。
- Regram 配置集中到 Pro，移除重复入口，统一导航、返回及主题文案。
- 全局设置搜索仅保留在 Pro 首页，修复搜索崩溃和搜索范围；长按设置复制深链。
- 改进 DC 测试、底栏布局、粘贴图片默认画质、聊天列表分隔线及本机账号数量处理。
- 回退导致安装包显著增大的备选图标资源方案。

## b34589–b34599：消息增强与更新基础

- 双击动作、菜单管理、发送者独立消息页、媒体信息、消息 ID、原始转发时间及编辑历史。
- 彩色二维码登录与令牌／DC／两步验证接续，资料角色徽章和加入后分组。
- 扩充翻译服务及 LLM 配置；逐步统一设置本地化与关闭弹窗行为。
- 建立 GitHub 正式版检查、本地签名、LCSign 清单安装、长期凭据保存、下载进度、描述文件匹配和跨重启缓存。
- 隔离签名 OpenSSL 与 Telegram 网络 BoringSSL，修复早期构建的连接崩溃；修复安装 URL 和清单节点路径。
