# 语音识别、链接预览与设置分类

## 语音识别

入口：设置 → Regram Pro → 常用功能 → 自定义语音识别，或翻译与语音 → 自定义语音识别。

页面可以选择 Telegram、Apple 或自定义 OpenAI-compatible 识别方式。自定义方式需要模型；OpenAI 官方接口还需要 API Key。可分别填写 Base URL、Endpoint、模型、语言和提示词，Endpoint 也可使用完整 URL。地址中不允许嵌入用户名和密码。密钥保存在本机钥匙串，不导出到设置备份。

内置测试音频可以检查当前配置。实际消息流程是获取完整媒体、提取音轨并转为单声道 M4A、上传、校验响应，再将识别文字写入原消息。支持普通云消息的语音与圆视频，排除秘密聊天、一次性媒体与预览。转换后文件上限为 25 MB。

转写结果可以通过原消息菜单复制、翻译、取消或重新识别。同一消息共享进行中的识别任务；滚动出屏幕不会重新上传。进入后台或移除所属账号会取消任务。来源与请求编号保护识别文本及对应翻译，避免已取消的请求或旧回调覆盖新结果。

默认 Telegram 转写继续使用 Telegram 的权限和额度。已有识别文本不会因为切换方式自动删除。

## 链接预览

入口：设置 → Regram Pro → 媒体与链接 → 链接预览修复。

默认关闭。开启后，预览请求使用已支持域名的规则，消息里的原始文字和链接不变。规则涵盖 X／Twitter、Instagram、TikTok、Reddit、Bluesky、Pixiv 及部分即时预览地址，并保存本地缓存。公共规则刷新失败时仍可使用已有缓存和内置规则。

X 和 Instagram 的服务域名可以单独设置；只填写域名，不填协议、路径或端口。无效输入不会替换保存值。规则或服务变更后，已打开聊天中的草稿会重新查询预览。结果仍取决于 Telegram 与对应的预览服务。

## 设置结构

Pro 首页保留常用入口，并将消息与输入、翻译与语音、隐私与过滤、媒体与链接、外观与界面、通知与提醒、管理与工具分开。照片、贴纸、录制、媒体加载、LLM 和语音接口等进入独立页面。

Regram 设置提供外观、聊天列表、分组、资料、动态和应用选项。原有设置键及保存值继续使用；搜索既能查分类入口，也能展开详细选项。

更新入口：Regram Pro → 管理与工具 → Regram 更新，或 Regram → 应用与高级 → Regram 更新。

## 图标

设置列表中的 Regram 图标使用用户提供的原始图片，Pro 图标使用默认应用图标。应用图标同时提供命名的 Icon Composer 资源与旧系统 PNG 回退，保留升级前的备选图标名称兼容。图标声明在代码签名前归一化。

系统通知的头部由 iOS 绘制，没有供通知扩展独立替换应用图标的公开接口。补齐图标资源与切换回调不等于已经验证所有系统界面随之更新；通知展示及缓存行为需要设备确认。参考 [Apple 的备选图标配置](https://developer.apple.com/documentation/xcode/configuring-your-app-to-use-alternate-app-icons)和[通知界面说明](https://developer.apple.com/documentation/usernotificationsui/customizing-the-appearance-of-notifications)。

## 验证范围

语法、资源声明、设置文案、配置与请求边界进行本机检查；完整编译与包校验结果记录在对应发布说明。真实 API 识别、第三方预览连通性、通知图标和设备覆盖升级仍需真机验证。编译成功不代表这些场景已经通过。
