# 语音识别、链接预览与设置分类

## 语音识别

入口：设置 → Regram Pro → 翻译与语音 → 语音转文字。

页面可以选择 Telegram、Apple 或自定义 OpenAI-compatible 识别方式。自定义方式需要模型；OpenAI 官方接口还需要 API Key。可分别填写 Base URL、Endpoint、模型、语言和提示词，Endpoint 也可使用完整 URL。地址中不允许嵌入用户名和密码。密钥保存在本机钥匙串，不导出到设置备份。

内置测试音频可以检查当前配置。实际消息流程是获取完整媒体、提取音轨并转为单声道 M4A、上传、校验响应，再将识别文字写入原消息。支持普通云消息的语音与圆视频，排除秘密聊天、一次性媒体与预览。转换后文件上限为 25 MB。

转写结果可以通过原消息菜单复制、翻译、取消或重新识别。同一消息共享进行中的识别任务；滚动出屏幕不会重新上传。进入后台或移除所属账号会取消任务。来源与请求编号保护识别文本及对应翻译，避免已取消的请求或旧回调覆盖新结果。

默认 Telegram 转写继续使用 Telegram 的权限和额度。已有识别文本不会因为切换方式自动删除。

## 链接预览

入口：设置 → Regram Pro → 媒体与链接 → 链接预览修复。

默认关闭。开启后，预览请求使用已支持域名的规则，消息里的原始文字和链接不变。规则涵盖 X／Twitter、Instagram、TikTok、Reddit、Bluesky、Pixiv 及部分即时预览地址，并保存本地缓存。公共规则刷新失败时仍可使用已有缓存和内置规则。

X 和 Instagram 的服务域名可以单独设置；只填写域名，不填协议、路径或端口。无效输入不会替换保存值。规则或服务变更后，已打开聊天中的草稿会重新查询预览。结果仍取决于 Telegram 与对应的预览服务。

## 应用内网页翻译

在应用内浏览器菜单选择“翻译网页”，使用当前消息翻译服务，目标语言跟随应用选择。Apple 网页翻译需要 iOS 18 或更新版本。逐批翻译可读取的正文，保留页面结构与链接；菜单可取消翻译或恢复原文。表单输入、可编辑内容、代码及不可见节点不提交；跳转或刷新页面会丢弃旧任务。无法访问的 iframe、图中文字及网站后续加载的内容不在当次范围内，可恢复原文后重新翻译。

## 底栏布局与诊断

底栏布局在“外观与界面 → 界面设置 → 底栏布局”。页面通过实际底栏组件预览，支持显隐、拖动排序、右侧独立按钮、顶部搜索、底部搜索样式、标签文字、按钮宽度和对齐。改动即时保存并应用，兼容旧版本的隐藏和宽度设置。

“管理与工具 → 性能与传输”提供手动 DC1–DC5 测试，使用当前账号的 Telegram 网络与代理路径。首次请求包含连接／授权建立时间，其后三次测量 RPC 往返时延，计算平均、最低与标准差，记录失败和超时。建立连接和单次请求各设 8 秒超时，可取消，离页、后台或切换代理时停止。DC1／3 标为 Miami、DC2／4 为 Amsterdam、DC5 为 Singapore；这些标签表示常用 DC 地区，不代表用户所在地。复制结果不包含账号身份、代理地址或密码、证书和密钥。保留下载传输统计与过滤性能测试。

## 设置结构

设置主页面仅保留 Regram Pro。首页只显示消息与输入、翻译与语音、隐私与过滤、媒体与链接、外观与界面、通知与提醒、管理与工具七个分类；每个功能只保留一个设置入口，移除常用区。仅 Pro 首页提供分类和功能关键词搜索，分类页和子页不添加设置搜索框。

语音转文字在同一页选择 Telegram、Apple 或自定义接口；LLM 只从翻译设置进入；照片、贴纸、录制和链接修复分别从媒体分类进入。媒体与下载子页只展示传输、媒体查看和播放选项。

链接预览修复采用 UIKit 的 `UITableView` 原生分组列表。LLM、字体和备份的提示窗统一使用可关闭的原生提示控制器；各设置页面共用 Regram 的导航栏和返回按钮，移除额外嵌套的系统导航栏。列表按导航高度、安全区和键盘高度设置内容及滚动指示器边距。

更新入口：Regram Pro → 管理与工具 → Regram 更新。

## 图标

设置列表中的 Regram 图标使用用户提供的原始图片，Pro 图标使用默认应用图标。主应用图标继续使用 Icon Composer，备选图标恢复使用 PNG 资源，保留升级前的备选图标名称兼容。已回退为全部备选图标生成高分辨率多外观资源及归一化声明的改动。

系统通知的头部由 iOS 绘制，没有供通知扩展独立替换应用图标的公开接口。补齐图标资源与切换回调不等于已经验证所有系统界面随之更新；通知展示及缓存行为需要设备确认。参考 [Apple 的备选图标配置](https://developer.apple.com/documentation/xcode/configuring-your-app-to-use-alternate-app-icons)和[通知界面说明](https://developer.apple.com/documentation/usernotificationsui/customizing-the-appearance-of-notifications)。

## 验证范围

语法、资源声明、设置文案、配置与请求边界进行本机检查；完整编译与包校验结果记录在对应发布说明。真实 API 识别、第三方预览连通性、通知图标和设备覆盖升级仍需真机验证。编译成功不代表这些场景已经通过。
