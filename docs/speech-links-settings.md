# 翻译、语音、链接与设置说明

本文补充接口配置和使用流程；完整入口表见[功能清单](features.md)，当前版本按 b34617 整理。

## 翻译与独立总结配置

LLM 翻译入口为 **设置 → Regram Pro → 翻译与语音 → 翻译 → LLM 翻译**。支持 OpenAI Chat Completions 和 Anthropic Messages 格式、模型列表、模型测试、提示词及温度。API Key 保存在本机钥匙串，不进入设置备份。

聊天上下文默认关闭；开启后最多带同一聊天／话题之前 5 条本机消息，每条最多 800 字。外部后端用于消息、聊天文本和发送前翻译，保护链接、代码及实体格式；富文本文章 AI 翻译仍使用上游路径。

消息总结从 **聊天与消息 → 消息总结接口** 配置，拥有独立开关、接口、模型及密钥。默认关闭，关闭时隐藏消息菜单及多选工具栏入口。可按当前会话／话题的一小时、今天、一天或自定区间获取文字，也支持单条／多选；确认上传范围后才调用。时间范围上限 5000 条及 64,000 字节文字，单条／多选最多 100 条，超限要求缩小范围。不上传媒体，排除秘密聊天、一次性及受保护内容。

## 语音与圆视频识别

入口：**翻译与语音 → 语音转文字**，选择 Telegram、Apple 或自定义 OpenAI-compatible Transcriptions API。

自定义方式可分别填写 Base URL、Endpoint、模型、语言及提示词；Endpoint 也可填写完整 URL，不允许地址内嵌用户名和密码。模型是必填项，密钥要求由所选接口决定。页面提供内置音频测试，密钥只保存于本机钥匙串。

实际流程为获取完整媒体 → 提取音轨 → 单声道 M4A → 上传 → 校验响应 → 显示在原消息。转换后上限 25 MB，支持普通云消息的语音和圆视频，排除秘密聊天、一次性媒体和预览。

结果可以复制、继续翻译、取消或重新识别。同一消息共享进行中任务，滚出屏幕不重复上传；进入后台或移除账号取消任务。请求编号隔离旧回调，避免覆盖新的转写及翻译。切换后端不删除已有文字，Telegram 后端仍遵守其权限及额度。

## 链接预览修复

入口：**媒体与链接 → 链接预览修复**，默认关闭。

开启后只修改预览请求，原消息文字和 URL 不变。规则支持 X／Twitter、Instagram、TikTok、Reddit、Bluesky、Pixiv 等域名；缓存刷新失败时保留已有缓存和内置规则。

X／Instagram 服务地址只填域名，不带协议、路径或端口；无效输入不替换保存值。规则变更后，已打开聊天的草稿重新查询预览。最终结果取决于 Telegram 与预览服务。

## 应用内网页翻译

在应用内浏览器菜单选择翻译网页，使用当前翻译服务及目标语言；Apple 路径需要 iOS 18 或更新版本。

分批处理可访问正文，保留结构与链接，可取消或恢复原文；表单、可编辑内容、代码、不可见节点不提交。导航／刷新丢弃旧任务，不处理图中文字和无法访问的 iframe，后续动态内容可恢复后重新翻译。

## 分类、导航与深链

Pro 首页按聊天与消息、输入与发送、翻译与语音、隐私与过滤、媒体与链接、外观与界面、通知与提醒、网络与传输、管理与工具九类组织。只在首页提供全局设置搜索，覆盖高级配置并定位结果；无常用区或重复设置入口。

链接预览采用 UIKit 分组列表；原生与 SwiftUI 页面共用 Regram 导航及返回方式。提示、密码输入、文件选择等使用可关闭的控制器，列表兼顾安全区、导航与键盘边距。

长按配置项复制深链，例如 `tg://rg/settings?page=llm&item=temperature`。链接与搜索共享目的地索引，只打开并定位，不包含保存值或私人数据，不执行安装／清除。会话和规则数据使用各自操作菜单，链接不携带其内容。

底栏布局位于 **外观与界面 → 界面设置 → 底栏布局**，在上游实际组件上预览显隐、排序、独立按钮、文字和宽度。聊天及设置必须保留、整体居中，自动宽度兼顾内容与点击间距；取消隐藏即时恢复，不提供独立色调强度设置。

性能诊断从 **网络与传输 → 性能与传输** 进入，DC 测试是二级页面；DNS 测试在 **DNS 与 IP 策略** 内，详见[功能清单](features.md)。更新位于 **管理与工具 → Regram 更新**，详见[更新流程](app-updates.md)。

## 图标与登录

Regram Pro 入口跟随当前 App 图标；切换成功后先同步选中状态，再延后校对系统读值，不因短暂旧值显示失败提示。应用暂不活跃时排队，回前台继续。主应用使用 Icon Composer，备选图标保留既有名称兼容；系统通知头部图标的实际刷新由 iOS 决定，需设备确认。

登录欢迎页使用 Regram 图片。手机号页右上角二维码按钮显示主题色二维码，支持令牌刷新、DC 迁移、两步验证及手动重试。二维码显示前必须取得有效 Telegram 登录令牌，连接超时与绘制失败是不同阶段；更换网络或节点可能改变连通结果，不能用离线图像解码证明登录成功。

## 验证范围

本机检查覆盖设置读写、模型请求边界、凭据隔离、旧回调、三种语言、深链、图标成功回调及构建资源。b34617 已完成完整构建及包校验；用户于 2026-10-15 确认的真机验收对应 b34616，b34617 新修正的真机结果尚未记录，详见[更新记录](changelog.md)。服务与系统行为的验证范围以实际测试的接口、设备和场景为准。
