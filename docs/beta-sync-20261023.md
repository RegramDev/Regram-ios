## 保留的分支差异

- Bundle ID 固定为 `com.regram.app`，App Group 为 `group.com.regram.app`；主应用和扩展使用同一个声明的共享容器。
- 保留构建输入、Bazel 和打包环节的身份约束，以及独立的 `REGRAM_BETA_BUILD_CONFIGURATION` Secret 引用；未修改仓库 Secret 或安装身份。
- 继续排除应用更新下载、证书导入、IPA 安装及更新实时活动。移除合并带回的更新页面、深链映射、图标分支和更新图片，图标生成器也不再生成更新活动资源。
- 保留当前 Regram UI、底栏和手势，以及本轮主线的权限提醒角标、LLM URL、Apple 转写、提及处理、消息合并和导航兼容修正。
- 分享扩展继续采用完整描述文件权限；新加入的键链／团队声明检查适用于 Beta 的分享扩展。

- Xcode 27.1 执行 `build-system/check-regram-features.py`，报告中 57 项全部通过；数量包含独立编译和执行条目，不表示执行了 57 次完整 App 测试。
- 设置目录回归确认更新搜索与更新深链不可达，同时保留新的权限提醒设置与其他主线设置入口。
- 分支审计确认身份和构建约束、独立 Secret 引用、三语更新文案及运行模块排除，并对相关 BUILD／Python 文件作语法检查。
- 12 个与主线有差异且仍存在的 Swift 文件通过 `swiftc -frontend -parse`；未借此声称完成 UI 模块编译。
- 8 个关键主线文件逐字节一致，包括版本、LLM、转写、可见消息处理、设置导航、资料页、消息合并及编辑器协议。
- Beta 相对合入主线的差异通过 `git diff --check`；继承的上游历史空白告警未批量整理。
- 本轮未在本地执行 Beta 整包构建、IPA 打包、真机／真实账号或覆盖升级验收。推送依照既有配置触发 Beta 的独立 Actions 构建，成功与否以对应运行结果为准。

本轮没有启动 Bazel 构建服务，也未清理任何可复用构建缓存。私人配置、回归日志及检查报告保留在被忽略的 `build-input/`。
