# Telegram 13.2 与底栏、文件组和缓存修复

2026-11-07，基于 Regram 最新远端 `6731118b5d1b28ad8370a182c1b00d5567efbdb8`（13.1.2 / b34646）建立独立工作树，使用 `sync/telegram-13.2-ui-cache-34647` 分支。原项目目录的图标、语言和 Mac 窗口相关未提交改动保留。

## 上游与兼容

- 原 Telegram 基线为 `279f89e4d4f63f17227bf877dc3d8990f22ecd58`，新基线为官方 `release-13.2` / `24638bc69bd083981b178dd1e7f921eebbf7fc46`。
- 合入 13.2 的消息与状态同步、News、原生 HLS、媒体选择器、无气泡模式及可访问性更新。采用上游新结构，移除已被上游替换的 rlottie 和旧 JS HLS 实现。
- 状态重放拆分后，把防撤回、机器人排除、本地置顶与归档、编辑历史、贴纸数量和群成员前台提醒接到新的执行入口；重置与历史确认删除也使用相同的防撤回判断。
- 保留 Regram 的可配置横向底栏，并为关闭动画时的导航项设置稳定身份。由上游功能配置启用的 News 等新增原生导航项继续显示；联系人根页面与从设置推入的页面分别保存，隐藏后重新开启不依赖已释放的控制器。
- 贴纸导出使用 13.2 的 tlottie 接口，原生 HLS 的首帧回调继续触发 Regram 的缩略图交接。
- 官方 iOS 标签锁定的 tgcalls `c1de0882de9013df246252129b95430f48b20eec` 无法从其公开仓库获取。使用同一官方 `TelegramMessenger/tgcalls` 中已公开的 `38dcea121f10638c42098f226f05c298a392f95c`，保留显式官方子模块地址；其余依赖按 13.2 固定版本检出。rules_apple 只应用仓库跟踪的兼容补丁，不改变提交指针。

## 三处修复

### 底栏开关

隐藏联系人或通话不再删除其保存的位置。再次显示恢复原有顺序和独立按钮位置；旧配置中已丢失的位置按默认相对顺序补齐。可见项目拖动以可见项下标定位，不把隐藏项当作拖动目标。显示项目的实际回调使用恢复操作。

搜索退出动画保留控件引用，退出过程中重新启用时复用原控件。完成回调同时检查当前配置和控件身份；取消退出也会清理仍被禁用的控件，避免留下旧搜索按钮。

### 文件组错位

上游 `7eeed1215cec3f97e44f2882674aaf2dfde3598d` 修复与用户截图一致的路径：缓存只包含文件组的最后一条时，补齐历史会原地复用消息节点；旧实现只在创建节点时决定父容器，导致复用节点用错坐标系，文件按钮越过日期、文字重叠且气泡下方留白。

合并结果保留每次布局重新确定父容器、移动时转换原有坐标、清理失效容器的全部处理，也覆盖文件组删除到只剩单条的反向切换。

### 最大缓存大小

账号不再只在启动时读取一次缓存设置，而是在账号生命周期内监听变化，立即把变更传给 MediaBox 清理器；相同设置不重复触发，账号释放时取消监听。

有限上限在完成扫描后每五分钟重新检查，继续下载后也能触发清理；扫描串行执行，更改配置或释放清理器会取消旧扫描及待执行任务。初次扫描仍沿用现有十秒延迟。不限大小不启动周期性容量扫描。保留上游的按访问时间淘汰、硬链接去重和缓存索引更新。
