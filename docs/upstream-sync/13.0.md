## 集成范围

上游新增钱包与应用锁实现、Rust MTProto 引擎、tlottie 渲染后端和新的相机接口；更新聊天列表邻居描述、消息合并、媒体、富文本及链接确认逻辑。使用新的 Bazel 9.2.0 和相应 Apple/Swift 构建规则，最低 iOS 版本随上游提高至 15.0。

本次处理 63 个冲突文件，主要适配如下：

- 保留 Regram 的 App Group 与重签名容器解析，同时配置新的 PasscodeEnvironment；通知扩展使用新的 Sender 与多账号名称实现，保留空通知、外部会话、提及/置顶策略、超时交付和 Siri entitlement 检查。重试打开账号元数据时改用上游 setupAccountManager，沿用新的应用锁初始化与迁移入口。
- 保留消息过滤、防撤回、翻译、快捷翻译缓存、隐藏标签栏、紧凑布局和媒体加载设置，并适配上游新增消息、贴纸及 UI 接口。已读状态补偿同步显式使用 willValidate=false：补偿完成后没有下一轮验证负责确认，读状态已消失时也应确认并结束同步。
- 将后置圆形视频相机设置接入新的 CameraLegacy；合并媒体选择器的新完成按钮参数，并按上游相邻按钮的方式保留旧式 UIButton 的高亮设置。
- 保留设置预览在主线程创建 UI 的修复，将 Regram 百分比滑块接入 ListViewItemNeighbors；显式标注布局节点与设置链接闭包的捕获关系，适配 Swift 6.4 的检查。新钱包交易与礼物文本页面补齐聊天专用过滤动作的枚举分支，保持其菜单默认禁用；余额入口保留原有关闭策略并移除因此不再使用的上游变量。
- 使用上游拆出的消息合并与 URL 模块；把旧系统的 URL 编码修复迁移到 UrlWhitelist，沿用新的登录信息隐藏链接确认逻辑。
- 将同向滚动的媒体预加载回调加入 ChatHistoryListViewBackend，在 ListViewImpl 与 CoreListChatHistoryBackend 中保持同一逻辑偏移阈值；显式保留非强制可见范围更新与默认转发选项。消息过滤导入使用类型化文件选择器并保留复制导入语义。
- 更新 FLEX、Playground 与 CloudKit guard 的 objc_library 显式加载；重新生成 rules_apple 兼容补丁。移除已被上游替换的 XcodeParse、旧 PremiumGiftScreen 和开发工具子模块。

按原有策略保留 Regram 功能。StoreKit 购买仍按原有非官方客户端策略禁用。订阅说明直接沿用 iOS 15 的 Markdown 文本与链接处理，移除已不在支持范围内的旧系统分支，避免 SDK 27 的 Group/TupleContent 可用性错误。
