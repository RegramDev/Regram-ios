# 归档、手势与设置显示修复

2026-10-22，基于已发布的 b34626 和源码 `3ebfb49f8a`，处理本轮八项问题，重点排查社群关联群组／频道归档后回到主列表。版本号仍为 13.0 / b34626，本轮尚未另行打包或发布新版本。

- 设置首页右滑返回聊天使用 `RGRootTabBackTransition`，此前没有普通导航转场所持有的 `.max` 刷新率请求。现复用 `SharedDisplayLinkDriver`，在跟手及收尾动画期间请求最高刷新率，完成、取消、中断及对象销毁时释放。既有快照阴影优化和导航状态处理保留。
- 完整移除禁用社区会话合并的开关、运行时判断、偏好读取、三语文案、搜索项、深链和备份字段。旧存储值不再参与显示，旧备份中的该字段被白名单过滤；社区汇总首次加载时按服务端合并状态重建列表归属。头像进入聊天／社区／箭头的独立设置保留。
- 移除「下拉归档自动进入」与「全局搜索结果从底部开始」的设置、偏好、三语资源、搜索、深链和备份字段。归档保留原生下拉露出及手动进入；全局搜索恢复原生列表和留白，不更改底部搜索栏入口。专用翻转列表模块及其构建依赖一并删除。
- 顶部标记图片本身没有细横条；iOS 27 的装饰窗口根控制器此前继承主窗口 Home 指示条策略，现改为独立自动隐藏，并在显示时请求系统刷新该策略。标记素材、偏移和主窗口 Home 指示条策略保留。
- 社群后台汇总和展开社群不再覆盖有效归档；缺少列表归属时读取服务端实际分组，并保护请求期间发生的手动归档／取消归档。归档、状态同步、汇总、成员更新、启动及取消归档的源码核对见[专项排查](community-archive-audit-20261022.md)。
- 「所有对话」标题选择显示模式和实际预览；当语言包长短标题相同时，提供三语的明确长短文案。选择器、顶部分组及底部分组使用同一标题解析。
- 截图标记页增加当前选择的大预览，行内预览从 44 点放大至 128 点宽，补充三语样式名称和稳定列表标识，保留选择及可访问性状态。

高刷新率采用 [Apple 推荐的显示同步请求](https://developer.apple.com/documentation/quartzcore/optimizing-iphone-and-ipad-apps-to-support-promotion-displays)，不能强制设备恒定 120 Hz。低电量、温度及系统调度仍会影响实际帧率。

本轮沿用用户跳过测试的要求，不运行功能回归、模拟器交互或真机测试，也不把这些项目标为通过。同步维护现有检查脚本的编译夹具，删除对已移除设置的旧引用；这不代表执行了检查脚本。

前两轮编译因用户追加功能移除、归档及界面问题而主动中止；缓存保留用于最终源码的重新编译。编译记录待本轮编译结束后补齐。没有实际测量 ProMotion 帧率，顶部横条消失的时机、标记预览及归档真实账号表现仍待设备确认。
