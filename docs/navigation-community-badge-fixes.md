## 横条后续复查（未发布）

2026-10-22，用户在 b34627 发布后提供截图，反馈顶部标记下方的细横条仍然存在。此前「测试没问题了」的总体反馈不能当作这一场景的逐项验收；自动隐藏策略没有解决该问题。

`RGAppBadgeOverlay` 原先将独立窗口缩到图片大小。Home 指示条的自动隐藏是系统策略，不能保证它在窗口显示或交互后始终不可见。现将装饰窗口的几何尺寸对齐主窗口，避免其系统底边落在图片下方；以 `CAShapeLayer` 遮罩将实际绘制限制在标记区域，图片和遮罩均从主窗口坐标转换，不改变标记素材及偏移。窗口沿用主窗口的 Home 指示条策略，继续禁止成为 key window 和拦截触摸。

验证使用 Xcode 27.0 的真实 UIKit SDK：修改的源文件完成 arm64、iOS 15 部署目标的对象编译，并编译为独立模拟器应用。在 iPhone 17 Pro／iOS 26.5 模拟器强制调用生产叠加路径，20 项检查通过，覆盖全尺寸窗口及 safe area、图片位置、绘制遮罩、尺寸变化、触摸穿透、主窗口 key 状态、App Lock 透明度、隐藏和空图、激活／停用通知，以及关闭和重新开启。通知检查使用测试应用主动发送的通知，不代表真实后台切换验收。对照有／无标记的稳定截图，标记下方包含导航及原生玻璃底栏的区域没有像素差异；该结果仅适用于本测试应用与模拟器环境。
