# Regram typography

Bundled unmodified OFL typefaces: JetBrains Mono 2.304, JetBrains Mono NL 2.304, Inter 4.1, Poppins, Lora, IBM Plex Sans/Serif/Mono/Sans SC, Source Sans 3 and Source Serif 4. The original 11 bundled families include 82 static faces. Noto Serif SC adds one unmodified variable font (wght axis), for 83 packaged font files. Plex Sans SC covers Chinese with upright Regular, Medium, SemiBold and Bold; its italic emphasis uses an oblique descriptor. Source Serif has no Medium face, so that weight uses its Regular face. Other bundled families include real Medium, Semibold and Bold with matching italics.

Upstream commits, unmodified download URLs, archive members and SHA-256 hashes are recorded in FONT-SOURCES.json. Original OFL 1.1 copyright and license notices are retained under Licenses/ and packaged with the app. Poppins and Lora are named in Anthropic's public brand-style example at https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md. They are offered under their own names; no Anthropic Sans/Serif/Mono font files are bundled because no redistribution grant was identified.

Fonts are registered lazily per family and process. Their actual PostScript names are read from CoreText descriptors: font filenames do not reliably match those names (for example, Plex abbreviates some weights). Missing resources fall back to UIKit; missing glyphs use the text renderer's normal fallback cascade.

English/Latin and Chinese are selected independently. English has 13 choices; Chinese has System, IBM Plex Sans SC and Noto Serif SC. Both selections respect the independent chat-message/main-interface area checkboxes. Han characters, CJK punctuation and full-width forms use the Chinese face; ASCII letters, digits and punctuation use the Latin face. A restricted CoreText cascade prevents CJK fonts from supplying Latin glyphs and prevents primary-font punctuation from bypassing the Chinese selection. Missing glyphs retain normal system fallback. The default is the system font. Display's explicit monospace, serif, rounded and camera designs are preserved; large emoji remain system-rendered. Plain and rich message renderers carry the message role through formatting and nested blocks. Font cache keys include both selected families. Appearance changes refresh presentation data and per-chat/forced themes without changing their colors or wallpapers.

Tests: AppearancePolicyTests.swift is a standalone Foundation executable. FontCascadeTests.swift runs against the production CoreText cascade implementation on the host and checks mixed runs, punctuation, supplementary Han coverage, ASCII digits, color emoji, and the Noto weight axis. `//Regram/RGTypography:TypographyTests` runs UIKit resource, scope, cache, notification, persistence and mixed-glyph rendering checks in an isolated test application, with no Telegram account or database.
